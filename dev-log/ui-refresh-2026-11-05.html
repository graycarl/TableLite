界面改版原型 / 把常驻控件减半

基于 manual/ 的线框图和 2026-11-05 Debug 实机截图。目标不是换一套皮肤，而是把 「连接、库、对象、数据、改动」这五件事重新排一次优先级：让常驻的东西变少，让重要的东西更清楚。

仅设计建议 · specs / manual 未改动 8 个界面 · 主窗口 / 过滤器 / 字段栏 / 查询 / 连接 / 偏好 / 结构 / 规范 可切换 浅色 / 深色 · 标注开关
01 / FEWER 常驻控件减半 没有改动时，不显示「放弃 / 预览 / 提交」；没有过滤时，不显示过滤条；没有选中行时，字段栏收起。
02 / HIERARCHY 一眼看出层级 连接只出现一次，标题说「当前在哪」，侧栏说「有什么」，网格说「数据是什么」。用字号、留白和 1px 线分层，而不是靠更多框。
03 / NEAR DATA 操作靠近数据 提交、筛选、行数这些和表数据有关的操作，放在网格边缘；全局操作（切库、搜索、刷新）留在工具栏。

Prototype 01主窗口：默认状态

连接只出现一次；没有改动时工具栏保持安静；选中行后字段栏才成为主角。

Prototype 02过滤器：从常驻面板到 popover

条件行还是条件行，但不再永久占用 200–300pt 高度；高级 SQL 也不再配一段常驻说明。
