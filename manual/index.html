TableLite 使用说明书整体界面一览

这份说明书按「你会在界面上看到什么、每个控件做什么」来组织。 每一章都用线框图画出界面，图上标着数字编号，下面的表格逐个解释这些控件的作用与快捷键。

这个工具是做什么的

TableLite 是一个在 macOS 上运行的 MySQL 客户端，用来日常查看数据、改数据、跑 SQL。 它是自用工具，不是通用产品，因此界面上没有多余的东西。

它擅长的事

  • 打开一张表，限制显示条数、排序、筛选着看
  • 选中一行后在右侧字段栏里改字段、增删行，改完先预览再一次性提交
  • 写 SQL 跑脚本，多个语句的结果分开看
  • 通过 SSH 跳板机连内网数据库
  • 把数据导成 CSV，也能从 CSV 导一批数据进来

它不做的事

  • 不改表结构（建表、加列、加索引请手写 DDL）
  • SQL 编辑器没有自动补全、没有格式化
  • 查询结果只读，只有表数据视图能改
  • 除 CSV 之外的导入导出格式（Excel、JSON、SQL dump）
  • 不支持 MySQL 之外的数据库
  • 数据网格没有撤销重做，回退靠「放弃全部改动」（SQL 编辑器里有撤销 / 重做）
先记住这一条

在界面上做的任何修改都不会立刻写进数据库。改动会先进入「变更暂存区」， 你确认无误后再点提交，所有改动打包在一个事务里执行——要么全部成功，要么全部回滚。 所以看到一个橙色的格子，说明这个改动还没生效，随时可以放弃。

主窗口长什么样

整个程序只有一个窗口，最上面是与系统标题栏合一的工具栏（红绿灯按钮与窗口标题就在这一行里，下沿有一条连接颜色带），往下是主体区。 主体区横向分三块：左侧栏（库、对象树）、标签内容区、右侧字段栏（表数据标签专有）。 下图的数字对应后面表格里的说明。

#控件作用快捷键
1连接切换器 显示当前连接与所在库。点开可以切换到别的连接、编辑连接、重新连接或断开。切换连接不会断开之前那个连接，只是换一组标签来看。⌘K 切换库
2新建查询 / 打开表 左边的 ‹ › 是标签的历史前进后退。+ 新建查询 开一个空的 SQL 标签；+ 打开表… 弹出表名搜索框，不用去左侧栏翻。⌘T
3变更操作组 放弃丢掉全部未提交修改；预览列出将要执行的 SQL；提交真的写库。按钮上的数字是待提交条数，为 0 时整组变灰。⇧⌘⌫ ⇧⌘P ⌘S
4连接颜色带 一条 2pt 的细带，用连接配置里的颜色着色。给生产库配红色，一眼就能看出当前在哪个环境。—
5库切换器与搜索框 上面是当前连接的库下拉，点开可以换库。下面是对象树搜索框，输入即过滤，会自动展开所有分组。⌘F 聚焦搜索
6对象树 当前库里的表、视图，分组标题上带数量。单击表打开数据视图，右键有更多操作。⌘R 刷新
7查询历史 / Console Log 左侧栏底部两个入口，只显示图标（时钟 / 终端），鼠标悬停时显示名称。查询历史记录你在编辑器里跑过的语句；Console Log 记录所有发给服务器的语句，包括客户端自动发的元数据查询。⇧⌘C
8标签栏 当前连接打开的所有东西：表数据、表结构、查询、历史、日志。当前标签用圆角底色块突出，顶边是连接颜色线。标题右边的橙点表示这个标签有未提交的改动。中键点击关闭标签。⌘W ⌘[ ⌘] ⌘1…⌘9
9标签内容区（数据网格） 占窗口最大的部分。表数据标签里是只读的数据网格：能选、能排序、能复制，但不能在格子里改值。查询标签里是编辑器加只读结果区，结构标签里是只读的列表。—
10右侧字段栏 表数据标签专有：选中一行后，这里列出它的全部字段（列名、类型、值），也是唯一能改数据的地方。顶部有「搜索字段」框。默认显示，用工具栏最右的 ▤ 或「视图 → 显示/隐藏右侧字段栏」开关，没有快捷键。—

怎么读这份说明书

  1. 先看第 2 章「界面结构」，把窗口各分区的职责弄清楚，后面所有章节都在这套框架里。
  2. 图上带数字的圆点和下面的表格一一对应。鼠标移到表格某一行，图上的圆点会变成橙色，方便定位。
  3. 橙色的提示框是需要特别注意的行为，红色的提示框是不可撤销的操作。
  4. 末尾的第 12、13 章是速查表：快捷键总表和提示文案规范，可以当参考手册随时翻。
