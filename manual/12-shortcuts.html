第 12 章快捷键总表

快捷键尽量沿用 TablePlus 的习惯，减少肌肉记忆冲突。 这一章是速查表，可以当参考手册随时翻。

最常用的八个

通用

快捷键行为
⌘N新建连接
⌘T新建查询标签
⌘W关闭当前标签
⌘,偏好设置
⌃⌘S显示 / 隐藏左侧栏
⇧⌘C显示 / 隐藏 Console Log
⌘[ / ⌘]上一个 / 下一个标签
⌘1 … ⌘9跳到第 N 个标签
⌘K切换数据库
⌘R刷新当前标签的数据 + 对象树
⌘O打开脚本文件
⇧⌘S脚本另存为
⇧⌘I导入 CSV
⇧⌘E导出

连接

快捷键行为
⇧⌘R重新连接
⇧⌘D断开连接

表数据

快捷键行为
⌘S / ⌘↩提交修改
⇧⌘P预览将要执行的 SQL
⇧⌘⌫放弃全部未提交的修改
⌘F打开 / 关闭行过滤器
⌥⌘F打开 / 关闭列过滤器
⌘I插入新行
⌘D复制选中的行
⌫删除选中的行（进入暂存）
⌘C / ⌘V复制 / 粘贴（网格上复制所选区域；右侧字段栏里粘贴单个值）
↩ 或双击打开右侧字段栏并聚焦该单元格对应的字段
Esc放弃字段编辑 / 关闭过滤器面板
Tab / ⇧Tab编辑中在字段之间移动
↑ ↓ ← →移动选中的单元格
⌘← / ⌘→跳到首列 / 末列
⌘↑ / ⌘↓跳到首行 / 末行（当前页内）
Space 或中键点击快速查看
⌘= / ⌘-增大 / 减小字号

查询编辑器

快捷键行为
⌘↩执行光标所在语句（有选中时执行选中部分）
⇧⌘↩执行全部
⌘.停止执行
⌘/注释 / 取消注释
⌘O打开脚本文件
⇧⌘S脚本另存为
⌘F查找
⌘Z / ⇧⌘Z撤销 / 重做

过滤器

快捷键行为
⌘I添加一条过滤条件
⇧⌘I删除当前这条过滤条件
Esc关闭过滤器面板（条件保留）
⌘I 在两种上下文里意思不同

在数据网格里 ⌘I 是「插入新行」；在过滤器面板里是「添加一条过滤条件」。 面板打开时 ⌘I 归面板管，关掉面板才轮到网格。

快捷键冲突时怎么办

TableLite 不提供快捷键自定义（Keymap），这是刻意的决定。如果某个键和你的系统或别的软件冲突：

  • 菜单栏里的每一项都写着对应的快捷键，可以从菜单点，行为完全一样。
  • 数据网格和编辑器里的右键菜单覆盖了绝大多数操作。
  • 系统偏好「键盘 → 快捷键」里可以看到并调整 macOS 层面的冲突。
