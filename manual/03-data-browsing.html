第 03 章浏览表数据

从对象树点一张表，就打开了它的数据视图。这一章讲表格长什么样、 右边那条「字段栏」怎么用、怎么限制显示条数、怎么排序，各种奇怪的内容 （NULL、BLOB、超长文本、图片）分别怎么显示。

数据网格

#元素含义
1行号列 最左边一列序号。点它可以选中整行；⌘ + 点击可以多选不连续的行。有已修改的行，行号上会带标记。
2主键列 列名加粗（不带图标）。有主键的表才可以编辑（见第 4 章）。
3外键跳转 ↗ 外键列的单元格后面带这个箭头。点一下会在新标签打开被引用的那张表，并自动只显示对应的那一行。
4NULL 灰色的斜体 NULL。注意它和空字符串不一样：空字符串显示为一格空白。
5二进制 长二进制显示成 «BLOB 12.3 KB»；很短的直接显示十六进制 0xDEADBEEF，省得还要点开看。
6超长文本 末尾带 … 表示被截断了。悬停会告诉你原始大小，点开或双击才去服务器取完整值。
7已修改的单元格 橙色底色 + 左上角小三角 = 有未提交的修改。行号列也会出现同样的标记。
8排序箭头 点列头排序：第一次 ▲ 升序，第二次 ▼ 降序，第三次取消。
9滚动条 按偏好可以自动隐藏。滚到表格底部就是本次加载的最后一行，不是整张表的最后一行。
10插入行 网格底部状态栏左侧的 ＋ 插入行，点一下等于按 ⌘I 新增一行。表或连接不可编辑时，这颗按钮整颗隐藏；表里没有数据时文案是「插入第一行」。
网格只读

数据网格本身只读，不能在格子里直接改值。双击单元格会跳到右侧字段栏里对应的字段并聚焦； 表或连接不可编辑时，双击改为打开快速查看。

各种内容分别怎么显示

内容类型显示理由
普通文本原样，超出列宽省略—
NULL灰斜体 NULL和空字符串区分开
数字右对齐方便比大小
布尔（tinyint(1)）0 / 1偏好了可改成复选框
日期时间原样显示服务器返回的文本不做时区转换，避免看错
超长文本截断 + …一次加载几十个 1 MB 的格子会卡死
BLOB / 二进制«BLOB 12.3 KB» / 0xDEADBEEF二进制没法当文本看
图片二进制«图片 PNG 45.2 KB»能识别出来的话直接说明是图片
几何类型«GEOMETRY 25 B»同样不解析
JSON一行紧凑显示不自动美化——美化过的 JSON 和实际存的值不一样，会误导
空字符串一格空白和 NULL 区分
已修改橙色底色见第 4 章
新增的行整行绿色底色见第 4 章
已删除的行整行删除线并变淡见第 4 章
超长内容的延迟加载

超过 4 KB 的文本和二进制列，打开表时只取前 4 KB。网格下方条会告诉你实际有多大 （比如 内容 1.2 MB）。选中该行（字段栏要展示完整值）、点「快速查看」或开始编辑某个字段时， 才会去服务器取这一行的完整值，中间会有一小段 loading。

如果表没有主键，就没办法准确定位到这一行，这些单元格会一直保持截断状态， 并提示 无法定位行以加载完整内容。

右侧字段栏

选中一行后，右边会出现一条「字段栏」，把这行的所有列按表定义的顺序纵向列出来。 它是表数据视图里唯一能改数据的地方：网格负责看，字段栏负责改。

#元素含义
1搜索字段 按列名过滤字段。输入时只显示命中的字段。
2字段计数 没有过滤时显示总数，例如 18 个字段；过滤后显示 显示 3 / 18。
3字段名 + 类型 字段名按表定义的顺序排列，用小字 + 次要色压在值上方；主键列带 🔑 并加粗。类型写在同一行右侧，字更淡，例如 varchar(255)，只读。
4值 字段栏里唯一能改数据的地方：点进去就能编辑，失焦或按 ↩ 写入暂存区，Esc 放弃。所有值统一左对齐，数字 / 日期时间 / 二进制用等宽数字。
5∅ 设为 NULL（常显淡灰，聚焦加深，NULL 时按下） 在 NULL 与上一个非 NULL 值之间切换。它在字段名行的最右端，所以值那一行能吃满整宽、左右边缘都齐。字段本来就是 NULL 时按钮呈按下状态。
6已修改标记 改过的字段橙色底色 + 左上角小三角；网格里对应的单元格与行号列同时出现相同标记，直到提交或放弃。
7加载完整内容… 这一行的大字段合计超过 8 MB 时不自动取，点它才去服务器取完整值。
8焦点行 字段栏始终跟随网格的焦点行：点哪个单元格，字段栏就显示它所在的那一行。
9拖拽边界 字段栏宽度可拖拽（260–560pt，默认 300pt），全局记住。有选中行时字段栏自动出现，未选中时收起；用工具栏最右的 ▤ 按钮或菜单「视图 → 显示 / 隐藏右侧字段栏」整体开关。

显示规则

  • 字段按表定义的列顺序排列，不受网格列显隐与列顺序影响：被列过滤器隐藏的列，在这里照样显示。
  • 每个字段分两层：上面一行是字段名（小字、次要色），下面一行是值（13pt、主色）。标题、字段名、值的文字压在同一条左缘线上（主键行的 🔑 占在字段名前），一眼能分清哪个是名字、哪个是值。
  • 字段之间用一条细分隔线断开，通栏（两端到头、不缩进），和顶部标题下面那条一样宽；最后一个字段下面不画。字段行没有悬停底色，鼠标扫过去字段栏不动 —— 整条底色只留给「已修改」的橙色标记。
  • 纵向留白紧凑：字段名与值之间只留一点空隙，行上下各留一点；多行字段按内容高度收缩，只有一行内容就占一行高、最多直接铺三行，不会空出一大块。
  • 所有值统一左对齐，不管它是文本、数字、日期还是二进制占位；数字 / 日期时间 / 二进制的数字串用等宽数字（字形还是普通正文字体，只让数字等宽），所以数字和文本的左缘分毫不差。
  • 字段名行右侧是完整类型（varchar(255)、int unsigned、decimal(10,2)），类型只读，不做类型转换。类型右边固定着 ∅ 槽位，所以每一行右端都收在同一条线上，不会因为有没有 ∅ 而参差。
  • 主键字段的字段名前带 🔑，字段名加粗。
  • 值按上一节的规则呈现（NULL、«BLOB 12.3 KB»、图片、JSON 等）。
  • 字段超过 10 个时顶部才出现搜索框；过滤时计数显示成 显示 3 / 18。

编辑

  • 每个字段的值就是一个编辑器，点进去就能改；编辑器按列类型自动选择（见第 4 章 §3）。
  • 失焦或按 ↩ 把值写进暂存区，不会立刻落库；Esc 放弃本次输入，恢复原值。
  • Tab / ⇧Tab 在字段之间移动。
  • 校验失败时输入框抖动并保持编辑状态，值不写入暂存区。
  • 改动过的字段橙色底色 + 左上角小三角；网格里对应的单元格与行号列同时出现相同标记。
  • 同一行改了多个字段，提交时合为一条 UPDATE。
  • 每个字段的 ∅ 按钮在字段名行右侧，始终在（平时是淡灰字形），不靠悬停冒出来；聚焦时加深并出现浅底，值是 NULL 时呈按下态。点一下在 NULL 与上一个非 NULL 值之间切换。
  • 值本身是 NULL 时，编辑器里显示灰色斜体 NULL 占位，与空字符串区分。所有类型一视同仁，二进制字段也是同样的灰色斜体、同样的左缘；二进制的 查看 在 NULL 时不可用，从文件导入… 仍然可用。
  • 多行字段的「展开」在聚焦、字段只读、或内容超过三行时出现（只读连接里的长文本也得打得开）；快捷键提示只在聚焦时出现，空值或一行内容不会因此多占高度。
  • 值平时不描边、不填底色，看起来就是一段文字；只有点进去才显出输入框的白底和焦点描边，多行字段也一样。只把鼠标移上去不会让值变成输入框的样子。

大字段

  • 选中一行时，字段栏要把值展示完整：超过 4 KB 的列会在选中行后自动去服务器取这一行的完整值（短暂 loading）。
  • 如果这一行的大字段合计超过 8 MB，就不自动取，改为在字段旁显示「加载完整内容…」按钮，点一下才取。
  • 表没有主键时无法定位行，大字段保持截断，并提示 无法定位行以加载完整内容。

情况字段栏里显示什么

开关与宽度

  • 默认显示。用工具栏最右的 ▤ 按钮，或菜单「视图 → 显示 / 隐藏右侧字段栏」切换；没有快捷键。
  • 宽度可拖拽（260–560pt，默认 300pt），全局记住；未选中行时字段栏收起，不占宽度。
  • 字段栏只在表数据标签里出现；查询结果、表结构、对象定义标签没有它。

显示条数与操作条

表数据每次只加载前若干行，默认 300 行，不做分页。打开一张百万行的表不会把一百万行都拉下来； 想看更靠后的数据，用排序或过滤器，或者把显示条数调大。网格下方常驻一条窄条： 左边是行数菜单、＋ 插入行 和大字段大小，右边是 筛选 / 列 / 导出 三个入口。

#控件作用
1行数菜单 全部行已加载时只写 4 行；被显示条数截断时写 300 / 约 12,480 行。总数是估算值，所以前面标了「约」。点开菜单可以改显示条数（100 / 300 / 1000 / 5000 +「自定义…」，上限 10000）或执行「精确统计」。加载超过 1 秒时后面会追加耗时，超过 10 秒再附带「取消」。
2＋ 插入行 新增一行，等于按 ⌘I。只在可编辑的表里出现；表或连接不可编辑时整颗按钮隐藏。表里没有数据时文案变成「插入第一行」。
3大字段大小 某个文本 / 二进制列的实际大小（如 bio 23.5 KB）。只在检测到大字段时出现，悬停有说明。
4筛选 / 列 / 导出 分别打开行过滤器（⌘F）、列过滤器（⌥⌘F）和导出面板（⇧⌘E）。导出的永远是当前过滤条件下的全部数据。
想看后面的数据怎么办

没有分页，所以没有「下一页」。想看更靠后的行，用排序把目标行排到前面，或用过滤器缩小范围， 也可以把显示条数调到更大。数据量很大时，用过滤器比单纯调大条数更实际。

列宽与列显隐

  • 拖列头之间的分隔线可以改列宽，宽度会记住，下次打开同一张表恢复。
  • 第一次打开一张表时，列宽会按当前看得见的那些值自动适配：用字体的实际宽度量（含列头），最窄 60pt、最宽 400pt 兜底。看不见的行不参与，一屏之外的超长文本不会把列拽宽。
  • 自己拖过的列从此以你为准，不会再被自动适配覆盖；自动适配出来的宽度不算「你定的」，下次打开会按当时可见的内容重新量。
  • 显示哪些列由列过滤器控制（⌥⌘F），见第 5 章。
  • 列的鼠标悬停提示里会显示完整类型，例如 `content` LONGTEXT NULL。

没有主键的表

直接置为只读

如果一张表没有主键（哪怕它有唯一索引），那么每一行都无法被可靠地定位。 此时数据仍然可以浏览，但表格进入只读状态：

  • 不能在网格里改值，也不能插入、不能删除
  • 右侧字段栏也变成只读——只能看，不能改
  • 双击单元格改为打开快速查看，而不是跳到右侧字段栏去编辑
  • 超长内容一直保持截断（因为无法定位行去取完整值）
  • 网格下方条上方显示橙色横幅：该表没有主键，行顺序不保证，且不可编辑

刷新

  • ⌘R 重新加载当前数据。
  • 刷新不会丢弃未提交的改动，也不会打断你：暂存原样保留，改动数只体现在标签标题的橙点与网格下方变更条上的待提交条数。
  • 唯一会没的是大字段的临时缓存——之前点开看过的完整内容会重新变回截断状态。
