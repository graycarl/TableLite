第 11 章偏好设置

按 ⌘, 打开。只有确实会被用到的选项，全部是「改了立刻生效」的即时设置， 没有「应用」按钮。

窗口长什么样

#元素说明
1分类列表 通用 / 连接 / 表数据 / SQL 编辑器 / CSV 与导出 / 界面 / Console Log。当前分类高亮。
2开关与输入框 所有选项即时生效。灰字是对这个选项的一句话解释。
3分类标题 和左侧选中的分类对应。

用 Excel 打开 CSV 乱码怎么办

把「导出文本编码」改成 UTF-8 BOM。Excel 默认不带 BOM 的 UTF-8 会按本地编码解释， 中文就变乱码了。

明确不做

偏好里不会出现这些东西
  • 主题自定义——浅色 / 深色跟随系统
  • 语法配色自定义
  • 快捷键自定义（Keymap）
  • 多套配置文件的切换

理由很简单：这是一个自用工具，多一套配置就多一套要维护和测试的东西。
