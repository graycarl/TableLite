第 07 章表结构视图

表结构视图是只读的。要看看、要复制都行，但不能在这里改—— 改结构请用查询编辑器手写 DDL。

这一章没有「编辑」按钮

新增列、删列、加索引、改类型、加外键，这些操作在界面上完全不存在。 想改结构，开一个查询标签写 ALTER TABLE。 这个取舍的理由是：图形化的结构编辑器要处理的边界情况极多（数据迁移、默认值、字符集转换……）， 而手写 DDL 对一个熟练用户来说又快又准确。

怎么打开

方式行为
对象树右键表 → 打开结构在新标签打开一个独立的结构标签
数据视图状态栏左边的 数据 / 结构 切换在同一个标签内切到结构视图

两种方式都可以，看你想同时对比几样东西。

列

#元素说明
1子页签 列 / 索引 / 外键 / 触发器 / 建表语句。当前页带下划线。表以外的对象只显示其中一两页。
2序号 列在表里的位置顺序。改列顺序要写 DDL。
3类型 完整类型，包括长度和精度：varchar(255)、decimal(10,2)、enum('a','b')。
4可空与默认值 没有默认值时显示 —；默认值就是 NULL 时显示 NULL。这两者含义不同，所以分开显示。
5主键 / 自增 / 字符集 属于主键和自增的打勾；字符集与排序规则只对文本类型显示，其它类型显示 —。
6数据 / 结构 切换 在同一个标签内切换数据视图和结构视图。也可以让它俩各占一个标签。
7刷新 重新读取结构（⌘R）。在查询编辑器里执行过 DDL 之后，已经打开的结构视图会标上「可能过期」。

结构可能过期时

你在查询编辑器里执行了 DDL（比如 ALTER TABLE ... ADD COLUMN）之后， 已经打开的结构视图内容就不再可靠了。这时视图顶部会出现一条提示：

明确不做

这一章的范围到此为止
  • 不在这里新增 / 修改 / 删除列、索引、外键、触发器
  • 没有图形化的建表向导
  • 没有表之间的 ER 关系图

这些都要手写 DDL，或者用专门的数据库设计工具。
