# 02 · 界面结构

## 1. 整体布局

单窗口，纵向从上到下：**工具栏**（与系统标题栏合一，不占额外一行）→ **连接颜色带**（2pt）→ **主体区**。

主体区横向分三块：

| 区域 | 内容 |
| --- | --- |
| 左侧栏 | 库切换、对象树、底部两个图标入口（查询历史 / Console Log），可拖拽宽度、可整体隐藏 |
| 标签内容区 | 标签栏 + 当前标签的内容。表数据标签里是数据网格，数据网格**只读** |
| 右侧字段栏 | 表数据标签专有：显示选中那一行的全部字段和值，并在这里编辑。默认显示，可隐藏 |

布局线框图见 [`../manual/02-workspace.html`](../manual/02-workspace.html)。

窗口从上到下：与系统标题栏合一的工具栏、连接颜色带、主体区。主体区横向分三块：**左侧栏**（库 / 对象树）、**标签内容区**、**右侧字段栏**。连接切换只在工具栏最左的切换器里做，左侧栏不重复放一个。

- 左侧栏宽度可拖拽，记住上次宽度
- 左侧栏可以整体隐藏（`⌃⌘S`）
- 右侧字段栏只在表数据标签里出现，宽度可拖拽（260–560pt，默认 320pt），记住上次宽度
- 右侧字段栏默认显示，用工具栏最右的 `▤` 按钮隐藏 / 显示；隐藏后标签内容区占满剩余宽度
- 工具栏底部有一条 2pt 的连接颜色带，用颜色区分生产 / 测试 / 开发

## 2. 工具栏

| 区域 | 内容 |
| --- | --- |
| 最左 | 连接切换器下拉；鼠标悬停时显示连接详情：`本地开发 · app_dev · MySQL 8.0.36 · utf8mb4 · 只读`，启用 SSH 隧道时多一行本地转发端口 |
| 接着 | 标签前进 / 后退（`⌘[` / `⌘]`） |
| 中间 | `+ 新建查询`、`+ 打开表…`（弹出表名搜索框） |
| 最右 | 变更操作组：`放弃`（`⇧⌘⌫`）、`预览`（`⇧⌘P`）、`提交`（`⌘S`），括号里显示待提交条数 |
| 最右端 | 右侧字段栏开关 `▤`（仅表数据标签可用，对应「视图 → 显示 / 隐藏右侧字段栏」） |

变更操作组只在数据标签激活时可用；条数为 0 时整体禁用（半透明）；只读连接上「提交」始终禁用，鼠标悬停说明原因。

## 3. 连接切换器

点工具栏最左的下拉，弹出：

```
┌────────────────────────────────────┐
│ ● 本地开发      app_dev       ✓    │
│ ● 预发布        app_staging        │
│ ● 🔒 生产        app_prod          │
│ ────────────────────────────────── │
│   新建连接…                  ⌘N    │
│   编辑当前连接…                    │
│   重新连接                   ⇧⌘R   │
│   断开连接                   ⇧⌘D   │
└────────────────────────────────────┘
```

- 每项：状态点 + 名称 + 当前选中的库
- 选择某一项即切换到该连接（**不断开**之前的连接）
- 切换后，标签栏变为该连接的标签集合

## 4. 库切换器

左侧栏顶部的下拉，列出当前连接可访问的所有数据库。

- 库多时下拉里带搜索框
- 不显示系统库（`information_schema`、`performance_schema`、`mysql`、`sys`），除非在偏好里打开
- 选中某个库后，对象树刷新为该库的内容
- 选中某个库后，SQL 编辑器里执行的语句默认就在这个库上执行，不需要写 `USE`
- 切换失败（库被删 / 没权限）时保持原来的库，并提示 `无法切换到数据库 X`
- 未选择库时，对象树显示「请选择一个数据库」

## 5. 对象树

### 结构

```
▾ 表 (128)
    users
    orders
    …
▾ 视图 (3)
    v_active_users
```

- 只显示当前选中库的对象
- 分组标题带数量，可折叠（折叠状态会记住）
- 分组内容在展开时才加载，加载期间显示占位行
- 表超过 500 个时只显示前 500 个，并在列表顶部提示 `仅显示前 500 项，请用上方搜索框查找`

### 搜索

- 输入即过滤，大小写不敏感，支持子串匹配
- 搜索时自动展开所有分组，只显示命中的对象
- `⌘F` 聚焦搜索框

### 交互

| 操作 | 行为 |
| --- | --- |
| 单击表 | 打开该表的数据视图；若已打开则切到那个标签 |
| 右键表 | `打开数据`、`在新标签打开`、`打开结构`、`复制表名`、`导出…`、`导入 CSV…`、`截断表…`、`删除表…` |
| 单击视图 | 在新标签打开视图定义（只读） |

### 底部入口

对象树下方一条固定入口栏，两个图标按钮：**时钟** = 查询历史，**终端** = Console Log，各自点开成一个独立标签。

- 只显示图标，不显示文字；鼠标悬停时显示入口名称

### 破坏性操作

`截断表` 和 `删除表` 无法进变更暂存，直接生效。因此：

- 只读连接下直接禁用
- 弹窗里先展示将要执行的 SQL
- 必须**手动输入表名**才能点确认按钮：

```
┌─ 删除表 ───────────────────────────────────────────┐
│  将要执行：                                        │
│    DROP TABLE `app_dev`.`orders`;                  │
│                                                    │
│  该操作不可撤销，且无法通过「放弃改动」回退。      │
│                                                    │
│  请输入表名 orders 以确认：                        │
│  [                    ]                            │
│                                                    │
│  [ 取消 ]                            [ 删除 ]      │
└────────────────────────────────────────────────────┘
```

### 刷新

- `⌘R` 刷新对象树与当前标签的数据
- 在 SQL 编辑器里执行了 DDL 后，自动刷新该库的对象树

## 6. 标签栏

### 标签类型

| 类型 | 标题 | 内容 |
| --- | --- | --- |
| 表数据 | 表名 | 数据网格 |
| 表结构 | `表名 · 结构` | 列的列表等（只读） |
| 对象定义 | 对象名 | 视图定义语句（只读） |
| 查询 | `查询 1`、`查询 2`… | SQL 编辑器 |
| 查询历史 | `查询历史` | 历史列表 |
| Console Log | `Console Log` | 语句日志 |

### 规则

- 打开一个已存在的同类标签 → 切到已有标签，不新建（按内容精确匹配；没有 TablePlus 那套「复用/固定」的复杂规则）
- `⌘T` 或工具栏 `+ 新建查询` → 新建查询标签
- `⌘W` 关闭当前标签；有未提交改动时先确认
- 有未提交改动时，标题右侧显示一个橙色圆点
- 查询标签可以右键重命名
- 中键点击标签 = 关闭
- 标签过多时横向滚动
- 当前激活的标签用圆角底色块突出，非激活标签只在悬停时显示淡底色；标签顶边用连接颜色标示（连接无颜色时用系统强调色）
- `⌘1`…`⌘9` 跳到第 N 个标签

### 关闭标签时

- 有未提交改动 → 弹窗三选一：`提交` / `放弃并关闭` / `取消`
- 查询标签的内容会作为草稿自动保存，关闭时不提示（除非该标签关联过磁盘文件且有改动）

## 7. 连接信息与进度显示

窗口底部**没有**常驻状态栏（2026-09-24 去掉）。原本放在那里的信息各归各处：

| 信息 | 在哪看 |
| --- | --- |
| 连接状态点、连接名 | 工具栏最左的连接切换器 |
| 服务器版本、字符集、`· 只读`、SSH 隧道本地端口 | 连接切换器的悬停详情 |
| 查询执行进度与结果概要 | 查询编辑器自己的状态栏 |
| 提交进度 | 表数据标签的提交遮罩 |
| 导出进度 | 导出面板 |
| 不可编辑的原因（无主键 / 视图 / 只读连接） | 网格底部条上方的提示条 |
| 表结构概况 | 表结构标签底部 |
| 进入只读连接这类瞬时消息 | 顶部轻提示（见 [12-feedback.md](12-feedback.md) §3） |

未提交改动不再有常驻提示条：工具栏的 `提交(N)` 角标与标签标题的橙点负责这件事。

## 9. 快捷键总表

### 通用

| 快捷键 | 行为 |
| --- | --- |
| `⌘N` | 新建连接 |
| `⌘T` | 新建查询标签 |
| `⌘W` | 关闭当前标签 |
| `⌘,` | 偏好设置 |
| `⌃⌘S` | 显示 / 隐藏左侧栏 |
| `⇧⌘C` | 显示 / 隐藏 Console Log |
| `⌘[` / `⌘]` | 上一个 / 下一个标签 |
| `⌘1`…`⌘9` | 跳到第 N 个标签 |
| `⌘K` | 切换数据库 |
| `⌘R` | 刷新当前标签的数据 + 对象树 |

### 连接

| 快捷键 | 行为 |
| --- | --- |
| `⇧⌘R` | 重新连接 |
| `⇧⌘D` | 断开连接 |

### 表数据

| 快捷键 | 行为 |
| --- | --- |
| `⌘S` / `⌘↩` | 提交修改 |
| `⇧⌘P` | 预览将要执行的 SQL |
| `⇧⌘⌫` | 放弃全部未提交的修改 |
| `⌘F` | 打开 / 关闭行过滤器 |
| `⌥⌘F` | 打开 / 关闭列过滤器 |
| `⌘I` | 插入新行（过滤器面板打开时 `⌘I` 归面板，见 [05-filtering.md](05-filtering.md) §1） |
| `⌘D` | 复制选中的行 |
| `⌫` | 删除选中的行（进入暂存） |
| `⌘C` / `⌘V` | 复制 / 粘贴（网格上复制所选区域；右侧字段栏里粘贴单个值） |
| `↩` 或双击 | 打开右侧字段栏并聚焦该单元格对应的字段 |
| `Esc` | 放弃字段编辑 / 关闭过滤器面板 |
| `Tab` / `⇧Tab` | 编辑中移到下一个 / 上一个字段 |
| `↑ ↓ ← →` | 移动选中的单元格（右侧字段栏跟着切到该行） |
| `⌘←` / `⌘→` | 跳到首列 / 末列 |
| `⌘↑` / `⌘↓` | 跳到首行 / 末行（已加载数据内） |
| `Space` 或中键点击 | 快速查看 |

### 查询编辑器

| 快捷键 | 行为 |
| --- | --- |
| `⌘↩` | 执行光标所在语句（有选中时执行选中部分） |
| `⇧⌘↩` | 执行全部 |
| `⌘.` | 停止执行 |
| `⌘/` | 注释 / 取消注释 |
| `⌘O` | 打开脚本文件 |
| `⇧⌘S` | 脚本另存为 |

> 快捷键尽量沿用 TablePlus 的习惯，减少肌肉记忆冲突。

## 10. 空状态

| 场景 | 显示 |
| --- | --- |
| 未连接 | 「选择一个连接开始」+ 连接列表 |
| 未选择数据库 | 「请选择一个数据库」 |
| 库里没有表 | 「当前数据库没有表」+「新建查询」按钮 |
| 表里没有数据 | 空网格 + 底部的 `＋ 插入行` 行（这一行上的文案显示为「插入第一行」） |
| 数据标签里没有选中行 | 右侧字段栏显示「选中一行以查看和编辑它的字段」 |
| 数据标签里选中多行 | 右侧字段栏显示「已选中 12 行 · 请只选一行」 |
| 查询没有结果 | 「查询成功，0 行，耗时 3 ms」 |
| 对象树分组为空 | 分组标题显示 `(0)`，展开后显示「（空）」 |
