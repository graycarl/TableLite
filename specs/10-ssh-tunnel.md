# 10 · SSH 隧道

## 1. 用途

数据库只允许内网访问时，通过一台跳板机转发连接。配置好后，用户不需要在终端里手动开隧道，连接行为与直连完全一致。

## 2. 配置项

在连接表单的「SSH 隧道」区域：

| 字段 | 说明 |
| --- | --- |
| 通过 SSH 连接 | 总开关 |
| SSH 主机 | 跳板机的域名或 IP；开启「使用 ssh config 别名」时，可以填 `~/.ssh/config` 里的 Host 名 |
| SSH 端口 | 默认 22 |
| SSH 用户 | 登录跳板机的用户名 |
| 认证方式 | 三选一 |
| 使用 ssh config 别名 | 勾选后完全交给系统 SSH 配置解析该主机 |
| 跳板机 | 形如 `user@proxy:22`，用于「先连 A 再跳 B」的场景 |

## 3. 三种认证方式

### 3.1 使用 `~/.ssh/config` 与 ssh-agent（推荐）

最省事的一种。选它之后，主机、端口、用户、密钥、`ProxyJump` 等全部由系统 SSH 配置文件决定，与用户在终端里敲 `ssh <别名>` 的行为完全一致。

- 适用场景：平时就是这么连的，或者已经在 ssh-agent 里加载了密钥
- 不需要在 TableLite 里填任何密码
- 用户的 `~/.ssh/config` 改动会立即生效

### 3.2 使用私钥

- 手动指定私钥文件路径，默认目录是 `~/.ssh`
- 私钥有口令时，第一次连接会弹出输入框，并可以勾选「记住口令」，之后保存在系统钥匙串里
- 支持常见的密钥类型（未加密的 RSA / ECDSA / Ed25519，以及带口令的同类密钥）

### 3.3 使用密码

- 用 SSH 账号密码登录跳板机
- 密码保存在系统钥匙串里
- 密码认证需要额外借助系统的密码询问机制，某些特殊环境（例如服务器禁用了密码登录）会失败并提示

## 4. 用户可见的行为

### 连接时

状态栏依次显示：

```
正在建立 SSH 隧道…
正在连接 MySQL…
```

隧道建立成功后，状态栏的提示里会带上隧道信息（仅在悬停详情里显示，主界面不显示本地端口，避免干扰）。

### 首次连接一台新主机

系统 SSH 会记录主机指纹。本工具的行为是：**自动接受首次出现的主机指纹**（等同于系统 SSH 默认的 `accept-new`），但**如果主机指纹发生变化（可能出现中间人攻击），会直接失败并展示警告**，不会静默忽略。

指纹变化的提示：

```
┌─ SSH 连接失败 ──────────────────────────────────────┐
│  @@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@  │
│  WARNING: REMOTE HOST IDENTIFICATION HAS CHANGED!   │
│  …                                                   │
│                                                      │
│  服务器的 SSH 指纹与本地记录不一致。这可能意味着     │
│  服务器被重装过，也可能存在安全风险。                │
│                                                      │
│  如果你确认服务器是安全的，请在终端里手动连接一次    │
│  并清理 ~/.ssh/known_hosts 中的旧记录。              │
│                                                      │
│  [ 关闭 ]                                            │
└──────────────────────────────────────────────────────┘
```

### 隧道断开

- 连接状态变为红点
- 状态栏提示 `SSH 隧道已断开`
- **不自动重连**，避免在用户不知情时反复建立隧道
- 用户点「重新连接」后，会重开隧道并重连数据库

### 断开连接

- 关闭连接时同时关掉隧道，不残留后台进程
- 退出 App 时也会清理所有隧道

## 5. 错误提示

| 情况 | 提示 |
| --- | --- |
| 跳板机无法连通 | `无法连接到 SSH 主机 bastion.example.com:22（连接超时）` |
| 用户 / 密码错误 | `SSH 认证失败：Permission denied (password).` |
| 私钥错误或需要口令 | `SSH 认证失败：私钥需要口令，或密钥未被接受` |
| 目标数据库不可达 | `SSH 隧道建立成功，但无法从跳板机访问 10.0.2.5:3306` |
| 主机指纹变化 | 见上方警告面板 |
| 跳板机上没有权限 | 原样展示 SSH 的错误输出 |

错误面板里始终提供一项「查看详细输出」，显示 SSH 进程的原始错误文本，方便排查。

## 6. 明确不做

- 不支持在界面里生成或管理 SSH 密钥
- 不支持 SSH 端口转发之外的其他 SSH 功能（如远程执行命令、SFTP）
- 不支持保存多个跳板机配置的层级（只支持一个 `跳板机` 字段）
- 不支持在 App 内编辑 `~/.ssh/config`（请用文本编辑器）
