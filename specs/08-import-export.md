# 08 · 导入与导出

## 1. 导出

导出只支持 CSV。

### 入口

| 入口 | 导出的内容 |
| --- | --- |
| 对象树右键表 → `导出…` | 整张表（不受当前过滤条件影响，导出全表数据） |
| 网格下方条 `导出` | 当前**过滤条件下**的全部数据（不是只导当前页） |
| 查询结果标签右键 → `导出结果…` | 该结果集的全部行 |
| 右键选中行 → `导出选中行…` | 选中的行 |

### 导出面板

```
┌─ 导出 ─────────────────────────────────────────────────────┐
│  源：app_dev.articles                                       │
│      （应用了过滤条件：status = 'published'，共约 12,480 行）│
│                                                             │
│  CSV 选项                                                   │
│    分隔符      [ , ▾ ]  (逗号 / 制表符 / 分号)              │
│    换行符      [ \n ▾ ] (LF / CRLF)                         │
│    [✓] 包含表头                                             │
│    文本编码    [ UTF-8 ▾ ]  (UTF-8 / UTF-8 BOM)             │
│    NULL 表示   [ 空字符串 ▾ ] (空字符串 / NULL 字面量)      │
│    日期格式    [ 原样输出 ▾ ]                               │
│                                                             │
│  [✓] 后台导出，完成后通知我                                 │
│                                                             │
│  保存到：[ ~/Downloads/articles.csv ]        [ 选择… ]      │
│                                                             │
│  [ 取消 ]                                       [ 导出 ]    │
└─────────────────────────────────────────────────────────────┘
```

### CSV 格式细节

- 含特殊字符（分隔符、引号、换行）的字段用双引号包裹，内部的双引号转义为两个双引号
- 表头默认使用列名
- `NULL` 与空字符串要能区分（默认用空字符串表示 `NULL`，可改为输出 `NULL` 字面量）
- 二进制内容输出为 `0x…` 十六进制文本

### 导出过程

- 导出在后台进行，大表导出时可以在其他标签继续工作
- 状态栏显示进度：`正在导出… 已写入 129,480 行（24.1 MB）`
- 可以随时取消；取消后已写入的部分会保留，并提示这是不完整的文件
- 完成后通知：`导出完成：129,480 行 → articles.csv`，并附「在 Finder 中显示」按钮
- 大表导出**不会**一次性把所有数据读进内存

### 导出时的错误

- 导出途中连接断开 → 提示「导出中断，文件不完整」，保留已写内容
- 目标文件不可写 → 提示具体原因
- 目标文件已存在 → 询问是否覆盖

## 2. CSV 导入

### 入口

- 菜单「文件 → 导入 CSV…」（`⇧⌘I`）
- 对象树右键表 → `导入 CSV…`

### 向导

**第一步：选文件与解析选项**

```
┌─ 导入 CSV（1/3）───────────────────────────────────────────┐
│  文件：~/Downloads/users.csv                    [ 选择… ]  │
│                                                            │
│  ┌─ 预览（前 20 行）──────────────────────────────────┐    │
│  │ id │ name  │ email           │ created_at          │    │
│  │ 1  │ 张三  │ zs@example.com  │ 2025-01-01 10:00:00 │    │
│  │ 2  │ 李四  │ ls@example.com  │ 2025-01-02 11:00:00 │    │
│  └─────────────────────────────────────────────────────┘    │
│                                                            │
│  分隔符    [ , ▾ ]   [✓] 首行是表头                         │
│  文本编码  [ 自动检测 ▾ ]                                   │
│  换行符    [ 自动检测 ▾ ]                                   │
│                                                            │
│  [ 取消 ]                              [ 下一步 ]          │
└────────────────────────────────────────────────────────────┘
```

- 编码默认自动检测，检测失败时提示手动选择
- 分隔符无法确定时提示手动选择
- 预览表格可以让用户直观确认解析是否正确

**第二步：列映射**

```
┌─ 导入 CSV（2/3）───────────────────────────────────────────┐
│  目标表：app_dev.users                                     │
│                                                            │
│  CSV 列        →   目标列            类型        说明       │
│  id            →   [ id         ▾ ]  int         主键       │
│  name          →   [ name       ▾ ]  varchar(50) 非空       │
│  email         →   [ email      ▾ ]  varchar(100)           │
│  created_at    →   [ (跳过)     ▾ ]                          │
│                                                            │
│  [ ] 遇到错误时继续导入其余行                               │
│  [ ] 导入前先清空目标表（TRUNCATE）                         │
│  [✓] 在事务中导入                                           │
│                                                            │
│  预计导入：12,480 行                                        │
│                                                            │
│  [ 上一步 ]                            [ 下一步 ]          │
└────────────────────────────────────────────────────────────┘
```

- 按列名自动匹配，匹配不上时默认「跳过」，可手动指定
- 每个下拉里列出目标表的所有列，并显示该列的类型与是否必填
- 「跳过」的列不参与插入
- 如果目标列不可为空但没有映射，导入前就给出警告

**第三步：执行**

```
┌─ 导入 CSV（3/3）───────────────────────────────────────────┐
│  正在导入…                                                  │
│  ████████████░░░░░░░░  █ 已写入 7,420 行 / 12,480          │
│                                                            │
│  成功 7,420   失败 0                                        │
│                                                            │
│  [ 取消 ]                                       [ 完成 ]    │
└────────────────────────────────────────────────────────────┘
```

### 导入行为

- 导入进度实时显示，可以取消
- 勾选「在事务中导入」时，要么全部成功，要么全部回滚；不勾选则逐行提交（部分成功）
- 取消导入时：事务模式回滚，非事务模式保留已导入的行并提示
- 有失败行时，导入结束后列出前 100 条失败原因，可导出为 CSV 以便修正后重试
- 导入完成后自动刷新对应表的标签

### 从 CSV 新建表

如果目标表还不存在，可以在入口处选择「导入到新表」：

- 读前 N 行推断列名与类型（全部按文本 / 整数 / 小数 / 日期时间推断）
- 推断结果可以在第二步里逐列修改（类型下拉里可选常见类型）
- 提供一个「全部按文本类型创建」的快捷选项（能覆盖大多数情况）
- 表名可编辑
- 生成建表语句并在执行前展示出来
- 只读连接下不可用

## 3. 明确不做

- Excel（`.xlsx`）导入导出
- 除 CSV 以外的导出格式（JSON、SQL INSERT）
- JSON 文件导入
- SQL dump 文件导入（用命令行工具更合适）
- 数据库备份 / 恢复
- 导入时的数据转换规则（例如大小写转换、截断长度）
