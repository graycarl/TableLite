# 03 · 浏览表数据

## 1. 打开表

从对象树单击表名，或在工具栏点 `+ 打开表…` 搜索表名，即可在标签里打开数据视图。

打开时会看到：

```
┌──────────┬──────────┬───────────────┬───────────────────┬─────────────┐
│ 🔑 id    │ name     │ email         │ content           │ created_at  │
├──────────┼──────────┼───────────────┼───────────────────┼─────────────┤
│ 1        │ 张三     │ zs@example.c… │ 这是一篇很长的文… │ 2025-01-01  │
│ 2        │ 李四     │ ls@example.c… │ «BLOB 12.3 KB»    │ 2025-01-02  │
│ 3        │ 王五     │               │ NULL              │ 2025-01-03  │
│ …                                                                       │
└─────────────────────────────────────────────────────────────────────────┘
```

- 最左有一列行号
- 主键列的表头带钥匙图标，列名加粗
- 外键列的单元格后带 `↗` 图标，点击可跳到被引用的行
- 网格本身**只读**，不能直接在格子里改值；选中一行后，右侧的「字段栏」会把这一行的全部字段列出来供查看与编辑（见 §7）

## 2. 分页

默认每页 300 行。底部状态栏显示：

```
行 1–300 / 约 12,480 行 · 第 1 页 · [300 行/页 ▾]   [ < ] [ > ]   跳到 [__]
```

规则：

- 每页行数可选 `100 / 300 / 1000 / 5000`，也可以手填（上限 10000）
- 行数是**估算值**，前面标注「约」。估算不准时显示「约 0 行（估算不可靠）」
- 状态栏提供「精确统计」按钮，点击后执行一次真正的计数。可能很慢，期间可以取消
- **打开表时绝不自动做精确计数**
- 翻到很深的页（偏移超过 10 万行）时提示：`偏移量很大，翻页会越来越慢；建议用过滤器缩小范围后再翻页`

## 3. 排序

- 点列头：第一次升序 ▲，第二次降序 ▼，第三次取消排序
- 按住 `⇧` 点列头可以追加多列排序，表头显示排序序号
- 取消排序后回到默认顺序（按主键）
- 换排序方式会回到第 1 页并重新加载

## 4. 单元格显示规则

| 内容类型 | 显示方式 |
| --- | --- |
| 普通文本 | 原样，超出列宽时省略 |
| `NULL` | 灰斜体 `NULL` |
| 数字 | 右对齐 |
| 布尔（`tinyint(1)`） | 显示 `0` / `1`（偏好里可改为复选框显示） |
| 日期时间 | 原样显示服务器返回的文本 |
| 文本超长 | 截断显示，末尾加 `…`。鼠标悬停显示「原始内容 1.2 MB，点开可查看完整内容」 |
| BLOB / 二进制 | `«BLOB 12.3 KB»`；短二进制显示为 `0xDEADBEEF` |
| 图片类二进制 | 显示 `«图片 PNG 45.2 KB»`，可快速查看预览 |
| 几何类型 | `«GEOMETRY 25 B»` |
| JSON | 单行紧凑显示（不做自动美化，避免误导） |
| 空字符串 | 显示为空（不是 `NULL`） |
| 已修改的单元格 | 橙色底色 |
| 新增的行 | 绿色底色的整行 |
| 已删除的行 | 整行加删除线并变淡 |

### 超长内容的延迟加载

为了不让一页数据变得巨大：

- 超过 4 KB 的文本 / 二进制列，打开表时只取前 4 KB，单元格末尾显示 `…`
- 状态栏提示这些单元格的实际大小，例如 `内容 1.2 MB`
- 选中一行（字段栏要展示完整值）、点「快速查看」或开始编辑某个字段时，才会去服务器取这一行的完整值（短暂 loading）
- **如果表没有主键或唯一键，无法定位行，则这些单元格保持截断状态**，并提示 `无法定位行以加载完整内容`

## 5. 列宽与列显隐

- 拖拽列头之间的分隔线调整列宽，宽度会被记住（下次打开同一张表恢复）
- 首次打开时按内容自动估算列宽（上限 400pt）
- 列显隐见 [05-filtering.md](05-filtering.md)
- 列的鼠标悬停提示里显示完整类型信息，例如 `` `content` LONGTEXT NULL ``

## 6. 选择与键盘操作

- 单击选中单元格；拖动或 `⇧` + 点击选中区域
- 行号列点击选中整行；`⌘` + 点击多选不连续的行
- 方向键移动选中单元格，`⌘←/⌘→` 跳到首/末列，`⌘↑/⌘↓` 跳到当前页的首/末行
- 选中后 `⌘C` 复制（格式见 §9）
- 右侧字段栏始终跟随「焦点行」：点哪个单元格，字段栏就显示它所在的那一行
- 选中多行时字段栏不显示字段列表，而是提示 `请只选一行`

## 7. 右侧字段栏

选中一行后，右边会出现一条「字段栏」，把这行**所有列**按表定义的顺序列出来。这是表数据视图里**唯一**能改数据的地方。

字段栏从上到下是：

| 部分 | 内容 |
| --- | --- |
| 顶部搜索框 | 按列名过滤字段；右侧显示字段总数或 `显示 3 / 18` |
| 字段行 | 一行一个字段，纵向排列，可滚动。每行含：列名（主键列带钥匙图标并加粗）、类型（灰色小字，只读）、值、右侧的 `∅`（设为 NULL）按钮 |

线框图见 [`../manual/03-data-browsing.html`](../manual/03-data-browsing.html)。

### 显示规则

- 字段按表定义的列顺序排列，**不受网格列显隐与列顺序影响**：网格里被列过滤器隐藏的列，在这里照样显示
- 列名旁边显示完整类型（`varchar(255)`、`int unsigned`、`decimal(10,2)`），类型**只读**，不做类型转换
- 主键字段的列名前带钥匙图标，列名加粗
- 值按 §4 的规则呈现（`NULL`、`«BLOB 12.3 KB»`、图片、JSON 等）
- 顶部有搜索框，按列名过滤字段；输入时只显示命中的字段，并标注 `显示 3 / 18`

### 编辑

- 每个字段的值就是一个编辑器，点进去就能改；`Tab` / `⇧Tab` 在字段之间移动
- 编辑器按列类型自动选择（对应关系见 [04-data-editing.md](04-data-editing.md) §3）
- **失去焦点或按 `↩`** 就把值写进暂存区（不会立即落库）；`Esc` 放弃本次输入，恢复原值
- 改动过的字段变橙色底色并出现小三角；网格里对应的单元格与行号列同时出现相同标记
- 同一行里改了多个字段，提交时合为一条 `UPDATE`
- 每个字段右侧有个 `∅` 按钮，点一下在 `NULL` 与上一个非 NULL 值之间切换

### 大字段

- 选中一行时，字段栏要把值展示完整：超过 4 KB 的列会在选中行后自动去服务器取这一行的完整值（短暂 loading）
- 如果这一行所有大字段加起来超过 8 MB，就不自动取，改为在字段旁显示「加载完整内容…」按钮，点一下才取
- 表没有主键或唯一键时无法定位行，大字段保持截断，并提示 `无法定位行以加载完整内容`

### 各种情况下的表现

| 情况 | 字段栏里显示什么 |
| --- | --- |
| 没有选中行 | `选中一行以查看和编辑它的字段` |
| 选中多行 | `已选中 12 行 · 请只选一行`（不显示字段列表） |
| 选中的行已标记删除 | 字段全部只读，顶部显示 `这一行已标记删除` 与 `撤销删除` |
| 选中的是新增行 | 字段全部为空，可以直接填；顶部标注 `新增行` |
| 表或连接不可编辑 | 字段正常显示但编辑器禁用，顶部写明原因（见 [04-data-editing.md](04-data-editing.md) §2） |

### 开关与宽度

- 默认显示；用工具栏最右的 `▤` 按钮或「视图 → 显示 / 隐藏右侧字段栏」切换
- 宽度可拖拽（260–560pt，默认 320pt），按表记住
- 只有在表数据标签里才有字段栏；查询结果、表结构、对象定义标签不显示

## 8. 快速查看

对内容较大或结构化的单元格，打开一个可调整大小的浮层查看完整内容。

触发方式：
- 选中单元格后按 `Space`
- 中键点击单元格
- 右键 → `快速查看`

浮层内容按类型呈现：

| 类型 | 呈现 |
| --- | --- |
| JSON | 格式化并支持折叠展开 |
| 长文本 | 等宽字体 + 行号 + 查找 |
| 二进制 / BLOB | 十六进制预览（前 64 KB）+ 文件类型识别 + 「导出为文件…」 |
| 图片 | 直接显示图片 + 「导出为文件…」 |
| 日期时间 | 原文 + 本地时区解析结果 |

`Esc` 关闭。

## 9. 复制

右键单元格或选中区域 → `复制为`：

| 菜单项 | 输出内容 |
| --- | --- |
| 复制单元格值 | 纯文本 |
| 复制行 | 一行，制表符分隔 |
| 复制选中行 | 多行，制表符分隔 |
| 复制整列的值 | 每行一个值 |
| 复制列名 | 逗号分隔的列名 |
| 复制为 JSON | JSON 数组对象 |
| 复制为 Markdown 表格 | 带表头与分隔线 |
| 复制为 CSV | 按偏好设置的分隔符 |
| 复制为 CSV（含表头） | 同上 + 首行表头 |
| 复制为 SQL INSERT | 可直接执行的插入语句 |
| 复制表结构 | 建表语句 |

- 复制超过 100 行时给轻提示：`已复制 12,480 行（2.1 MB）`

## 10. 外键跳转

- 外键列的单元格显示 `↗`
- 点击后在**新标签**打开被引用的表，并自动按被引用主键值过滤，只显示那一行
- 若被引用的表已经在其它标签打开，仍然新开一个标签（因为过滤条件不同）

## 11. 无主键的表

如果表既没有主键也没有可用的唯一键：

- 数据仍然可以浏览
- 状态栏显示：`该表没有主键或唯一键，分页顺序不保证，且不可编辑`
- 表格进入只读状态（不能编辑、不能插入、不能删除）
- 右侧字段栏也变成只读（只能看，不能改）
- 双击单元格改为打开快速查看（而不是跳到字段栏去编辑）
- 超长内容保持截断（因为无法定位行）

## 12. 刷新

- `⌘R` 重新加载当前页
- 刷新会清空大字段的临时缓存（截断重新变回截断状态）
- 刷新**不会**丢弃未提交的改动；如果有未提交改动，刷新前会提示

## 13. 性能预期

| 场景 | 目标 |
| --- | --- |
| 打开一张 100 万行的表（默认分页） | 500 毫秒内显示首屏 |
| 滚动 | 稳定流畅 |
| 切换分页 | 1 秒内（受服务器与网络影响） |
| 字段栏里编辑到界面反馈 | 立刻，无等待 |
