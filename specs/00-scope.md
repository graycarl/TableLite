# 00 · 需求与范围

## 1. 产品定位

一个**自用**的 macOS 原生 MySQL 客户端，用于日常查看数据、改数据、跑 SQL。

- 使用方式：本地安装的桌面 App，双击即用
- 目标用户：作者本人（熟悉 TablePlus，也熟悉 SQL）
- 界面语言：中文（SQL 关键字与协议术语保持英文）

## 2. 功能范围

### 2.1 做什么

**连接**
- 连接 MySQL
- 配置项：主机、端口、用户、密码、数据库、字符集、SSL 开关
- 通过 SSH 隧道连接（支持 `~/.ssh/config`、私钥、密码、跳板机）
- 保存多个连接，记住密码
- 给连接指定颜色、标记为只读
- 查询超时、连接保活

**看数据**
- 对象树浏览库、表、视图，支持模糊搜索
- 表数据分页浏览、点列头排序、调整列宽、隐藏列
- 单元格富显示：NULL、二进制、超长文本、JSON、日期
- 快速查看（大窗预览单元格内容）
- 复制单元格 / 行 / 多行 / 整列，多种格式

**改数据**
- 选中一行后，在右侧「字段栏」里逐字段查看完整值并编辑（数据网格本身只读）
- 新增行、复制行、删除行
- 改动先暂存，可以预览将要执行的 SQL
- 一次性提交（要么全部成功，要么全部回滚）
- 可以放弃全部改动

**跑 SQL**
- SQL 编辑器，带语法高亮、行号、当前语句高亮
- 执行当前语句 / 执行全部
- 多语句结果按语句分标签展示
- 结果可排序、复制、导出、快速查看
- 查询历史（可搜索、可清空）
- Console Log（记录所有发给服务器的语句）

**看结构**
- 表结构只读视图：列、索引、外键、触发器、建表语句
- 视图定义只读查看：创建视图的完整语句；也能在视图的结构里看它的列

**导入导出**
- 导出数据为 CSV
- 从 CSV 导入数据

**过滤**
- 行过滤（多条件组合）
- 列过滤（控制显示哪些列）

### 2.2 不做什么

| 项 | 说明 |
| --- | --- |
| 其他数据库 | 只支持 MySQL，不做 PostgreSQL / MariaDB / SQLite / Redis 等 |
| 函数 / 存储过程 | 对象树里不列出，也没有定义查看页；要看定义就在编辑器里跑 `SHOW CREATE PROCEDURE` / `SHOW CREATE FUNCTION` |
| 表结构编辑 | 建表、改列、加索引只能手写 DDL |
| SQL 自动补全 | 编辑器只做语法高亮 |
| 密码二次确认（Safe Mode） | 不做；由「预览 + 提交」和「只读模式」替代 |
| 全局跳转搜索（Open Anything） | 不做 |
| 查询收藏、关键字绑定 | 不做 |
| SQL 格式化 / 美化 | 不做 |
| 监控面板（Metrics Board） | 不做 |
| 用户与权限管理 | 不做 |
| 备份 / 恢复 | 不做，需要时用命令行工具 |
| 插件系统 | 不做 |
| AI / LLM 辅助 | 不做 |
| 编辑器分屏 | 不做 |
| 编辑查询结果集 | 查询结果只读，只有表数据视图可编辑 |
| 在数据网格里直接改单元格 | 不做；网格只读，字段值统一在右侧字段栏里改 |
| 字段栏里的类型转换（cast） | 不做；类型只读展示 |
| 连接分组 / 连接导入导出文件 | 不做 |
| 命令行打开连接（deeplink） | 不做 |
| 自动更新、崩溃上报、授权激活 | 不做 |
| 浅色 / 深色主题自定义 | 跟随系统即可 |
| 撤销 / 重做 | 数据网格内不提供，用「放弃全部改动」整体回退 |

### 2.3 相对 TablePlus 的简化

| 项 | TablePlus | TableLite |
| --- | --- | --- |
| 窗口层级 | 窗口 > 工作区 > 标签 三层 | 单窗口；连接用顶部下拉切换 |
| 标签复用规则 | 未修改则复用，有改动则固定 | 不复用；同一对象已打开则切到已有标签 |
| 密码二次确认 | 5 档 | 无，靠预览与提交 |
| 多结果集 | 最多 100 个标签 | 一排标签，超过 24 个折叠 |
| 行数显示 | 估算 | 估算（标注「约」），可手动精确统计 |
| 无主键的表 | 用所有列拼条件 | 直接置为只读 |
| 变更暂存 | 每个标签独立 | 每个标签独立（同 TablePlus） |
| 编辑入口 | 网格内联编辑 + 右侧行详情栏 | 只有右侧字段栏可编辑，网格只读 |
| 大数据列 | 整列拉取 | 超长列先取前 4 KB，点开时再取完整值 |

## 3. 已确认的产品决策

| # | 决策点 | 结论 |
| --- | --- | --- |
| D1 | 功能分层 | 核心功能全做；额外只保留「快速查看 / CSV 导入 / Console Log」 |
| D2 | SSH 隧道 | 需要，且要支持 `~/.ssh/config`、私钥、密码、跳板机 |
| D3 | 产品形态 | 自用工具，本地 App，不做签名分发、不做自动更新 |
| D6 | 窗口模型 | 单窗口 + 连接下拉切换 + 对象/查询标签 |
| D7 | 变更暂存作用域 | 每个标签独立，只提交当前标签 |
| D8 | 提交语义 | 一批改动包成一个事务，出错全部回滚 |
| D9 | 无主键的表 | 置为只读，并在界面说明原因（唯一索引不算数） |
| D10 | 查询结果集 | 只读 |
| D11 | 表数据加载 | 分页加载，默认每页 300 行 + 行数估算 |
| D12 | 多语句结果 | 一排标签，每条语句一个 |
| D13 | 行详情侧栏 | 做，即右侧「字段栏」，是表数据唯一的编辑入口；默认显示，工具栏按钮切换 |
| D14 | 只读模式 | 做，按连接开关 |
| D15 | 大数据列 | 默认只取前 4 KB，点开/编辑时再取完整值 |
| D16 | 数据网格 | 只读；不能直接改单元格，只能选中行后在字段栏里改 |

> 技术选型（数据库访问方式、SSH 实现方式、界面框架、工程组织方式）见 [`../docs/tech-designs/01-architecture.md`](../docs/tech-designs/01-architecture.md)。

## 4. 非目标

- 不追求与 TablePlus 功能对等
- 不支持多人协作、云端同步、跨设备
- 不做数据库设计工具（ER 图、迁移管理）
- 不追求跨平台
