# 07 · 表结构视图

表结构是**只读**的。要看、要复制，但不能在这里改（改结构请用 SQL 编辑器手写 DDL）。

## 1. 入口

| 方式 | 行为 |
| --- | --- |
| 对象树右键表 → `打开结构` | 在新标签打开 |

结构视图**永远占自己的标签**，入口就这一个，数据视图与结构视图之间没有切换按钮。因此同一个表可以同时开着 `users`（数据）和 `users · 结构` 两个标签。

## 2. 内容

结构视图顶部是一排子页签：

```
[ 列 ]  [ 索引 ]  [ 外键 ]  [ 触发器 ]  [ 建表语句 ]
```

### 2.1 列

| 列名 | 说明 |
| --- | --- |
| 序号 | 列在表中的位置 |
| 列名 | |
| 类型 | 完整类型，例如 `varchar(255)`、`decimal(10,2)`、`enum('a','b')` |
| 可空 | `是` / `否` |
| 默认值 | 没有默认值时显示 `—`；默认值为 NULL 时显示 `NULL` |
| 主键 | `✓` 表示属于主键 |
| 自增 | `✓` |
| 字符集 / 排序规则 | 仅文本类型显示 |
| 备注 | 列注释 |

主键列整行加粗。表的注释显示在这一页的顶部。

### 2.2 索引

| 列名 | 说明 |
| --- | --- |
| 索引名 | |
| 类型 | `PRIMARY` / `UNIQUE` / `普通` / `全文` / `空间` |
| 包含的列 | 按顺序列出，`desc` 的列标注 |
| 基数 | 估算的唯一值数量 |
| 备注 | 索引注释 |

### 2.3 外键

| 列名 | 说明 |
| --- | --- |
| 约束名 | |
| 本表列 | |
| 引用表 | `库.表` |
| 引用列 | |
| 删除时 | `CASCADE` / `SET NULL` / `RESTRICT` / `NO ACTION` |
| 更新时 | 同上 |

引用表的表名可点击，跳到那张表。

### 2.4 触发器

| 列名 | 说明 |
| --- | --- |
| 名称 | |
| 时机 | `BEFORE` / `AFTER` |
| 事件 | `INSERT` / `UPDATE` / `DELETE` |
| 语句 | 触发器体，多行折叠显示，点击展开 |

### 2.5 建表语句

完整显示数据库返回的建表语句，等宽字体、语法高亮。

顶部有 `复制` 按钮。对象是视图时，这个页签改叫「定义」，内容是创建视图的完整语句（视图的子页签见 §3）。

## 3. 与其他对象的对应

| 对象类型 | 结构视图内容 |
| --- | --- |
| 表 | 上面五页全部 |
| 视图 | 只显示「列」与「定义」两页；「定义」就是 §2.5 那一页 |

视图的定义页用与查询编辑器相同的高亮与只读文本视图展示，顶部提供 `复制` 与 `在新查询标签中编辑` 两个按钮。后者把定义原文填进一个新的查询标签，用户改完自己执行。

## 4. 刷新

- `⌘R` 重新读取结构
- 在 SQL 编辑器里执行了 DDL 后，已打开的结构视图会标记为「可能过期」，显示一个刷新提示条

## 5. 概况条

表结构标签底部一条概况条，只显示当前表的概况，没有操作按钮：

```
11 列 · 3 索引 · 1 外键 · 0 触发器
```

视图只有「列」与「定义」两页，没有索引 / 外键 / 触发器，不显示这条概况。

刷新的入口见 §4：`⌘R`，或点「可能过期」提示条里的 `刷新`。

## 6. 明确不做

- 在这里新增 / 修改 / 删除列、索引、外键、触发器
- 图形化的建表向导
- 表之间的 ER 关系图

这些都需要手写 DDL。
