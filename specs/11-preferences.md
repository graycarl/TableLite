# 11 · 偏好设置

`⌘,` 打开。只有确实会被用到的选项，全部是「改了立刻生效」的即时设置。

## 1. 通用

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 恢复上次打开的标签 | 开 | 重启 App 后恢复上次的连接与标签；只恢复骨架，不自动重连 |
| 恢复上次的脚本内容 | 开 | 查询标签重新打开时恢复上次的编辑内容 |
| 空闲自动断开连接 | 开 | 空闲 5 分钟且没有标签引用时自动断开 |
| 报告崩溃 | 关 | 不做崩溃上报，此项目前不出现 |

## 2. 连接

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 默认查询超时 | 300 秒 | 新建连接时的默认值 |
| 默认保持连接活跃 | 开 | 新建连接时的默认值 |
| 心跳间隔 | 30 秒 | |
| 同时保持的连接数上限 | 8 | |

## 3. 表数据

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 每页行数 | 300 | 可选 100 / 300 / 1000 / 5000 |
| 字号 | 13 | 网格正文的文字大小 |
| 交替行底色 | 开 | 关闭后所有行同色 |
| 自动隐藏滚动条 | 开 | |
| 超长内容截断阈值 | 4096 字节 | 超过该长度的文本 / 二进制列会延迟加载 |
| `NULL` 的显示文本 | `NULL` | 可改为 `(null)`、`<空>` 等 |
| 把 `tinyint(1)` 显示为复选框 | 关 | 打开后该类型以三态复选框呈现 |
| 显示右侧字段栏 | 开 | 关闭后打开表时不显示字段栏，可用工具栏按钮再打开 |
| 右侧字段栏宽度 | 记忆 | 可拖拽，260–560pt |
| 记住每张表的列宽与列显隐 | 开 | |
| 记住每张表的过滤条件 | 开 | |

## 4. SQL 编辑器

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 字体 | 系统等宽字体 | 可选系统已安装的等宽字体 |
| 字号 | 13 | |
| 缩进宽度 | 4 空格 | |
| 默认执行行为 | 执行当前语句 | 可改为「执行全部」 |
| 遇到错误时停止 | 开 | 关闭后会继续执行后续语句，一次看到所有错误 |
| 高亮当前语句 | 开 | |
| 显示行号 | 开 | |
| 自动保存脚本草稿 | 开 | |

## 5. CSV 与导出

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 默认分隔符 | 逗号 | 逗号 / 制表符 / 分号 |
| 默认换行符 | LF | LF / CRLF |
| 导出时包含表头 | 开 | |
| 导出文本编码 | UTF-8 | UTF-8 / UTF-8 BOM |
| `NULL` 的导出形式 | 空字符串 | 空字符串 / `NULL` 字面量 |

## 6. 界面

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 显示系统数据库 | 关 | 打开后对象树里显示 `information_schema` 等 |
| 左侧栏宽度 | 记忆 | |
| 编辑器 / 结果区分割比例 | 记忆 | |
| 界面语言 | 中文 | 当前仅中文 |

## 7. Console Log

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 保留条数 | 5000 | 内存中保留的最近条数 |
| 写入日志文件 | 关 | 打开后写入本地日志，按天轮转保留 7 天 |
| 打开时自动滚到底部 | 开 | |

## 8. 明确不做

- 主题自定义（浅色 / 深色跟随系统）
- 语法配色自定义
- 快捷键自定义（Keymap）
- 多套配置文件的切换
