# 11 · 偏好设置

`⌘,` 打开。只有确实会被用到的选项，全部是「改了立刻生效」的即时设置。

偏好设置只有四类：**通用 / SQL 编辑器 / 表数据 / 高级**。

## 1. 通用

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 外观 | 跟随系统 | 亮色 / 暗色 / 跟随系统，三选一（分段控件）。改完立刻生效，系统外观变化时实时跟随 |
| 恢复上次的脚本内容 | 开 | 重新打开查询标签（含连接后还原出来的标签）时恢复上次的编辑内容 |
| 空闲自动断开连接 | 开 | 空闲 5 分钟且没有标签引用时自动断开 |
| 显示系统数据库 | 关 | 打开后对象树里显示 `information_schema` 等 |

启动行为不做成开关：每次启动都进连接列表，连上某个连接后才还原它的标签现场（见 [01-connections.md](01-connections.md) §1）。

## 2. SQL 编辑器

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 字体 | 系统等宽字体 | 可选系统已安装的等宽字体 |
| 字号 | 13 | |
| 缩进宽度 | 4 空格 | |
| 默认执行行为 | 执行当前语句 | 可改为「执行全部」 |
| 遇到错误时停止 | 开 | 关闭后会继续执行后续语句，一次看到所有错误 |
| 高亮当前语句 | 开 | |
| 显示行号 | 开 | |
| 自动保存脚本草稿 | 开 | 关闭后编辑内容不再定时自动落成草稿，状态栏会以橙色 `未保存` 提醒（`06-query-editor.md` §2） |

## 3. 表数据

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 默认显示行数 | 300 | 可选 100 / 300 / 1000 / 5000 |
| 字号 | 13 | 网格正文的文字大小 |
| 交替行底色 | 开 | 只作用于有数据的行；空白区域不加斑马纹 |
| 自动隐藏滚动条 | 开 | |
| 超长内容延迟加载 | 开 | 打开后超长文本 / 二进制列先取截断值，需要时再加载完整内容 |
| `NULL` 的显示文本 | `NULL` | 可改为 `(null)`、`<空>` 等 |
| 把 `tinyint(1)` 显示为复选框 | 关 | 打开后该类型以三态复选框呈现 |
| 显示右侧字段栏 | 开 | 关闭后选中行也不显示字段栏，可用工具栏按钮再打开 |
| 右侧字段栏宽度 | 全局记忆 | 可拖拽，260–560pt，默认 300pt；全局共用，不按表区分 |
| 记住每张表的列宽与列显隐 | 开 | |
| 记住每张表的过滤条件 | 开 | |

## 4. 高级

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 默认查询超时 | 300 秒 | 新建连接时的默认值 |
| 默认保持连接活跃 | 开 | 新建连接时的默认值 |
| 心跳间隔 | 30 秒 | |
| 同时保持的连接数上限 | 8 | |
| 超长内容截断阈值 | 4096 字节 | 超过该长度的文本 / 二进制列会延迟加载 |
| 编辑器 / 结果区分割比例 | 40% / 60% | 拖拽分隔条后记住 |
| Console Log 保留条数 | 5000 | 也可在日志标签的菜单里改 |
| Console Log 写入日志文件 | 关 | 按天轮转保留 7 天 |
| Console Log 打开时自动滚到底部 | 开 | |

CSV 的分隔符 / 换行符 / 表头 / 编码 / `NULL` 形式在**导出面板**里直接改，并记住上次选择。界面语言只有中文、崩溃上报不出现，因此不再展示。

## 5. 明确不做

- 语法配色自定义（外观只有亮色 / 暗色 / 跟随系统三选一）
- 主题包 / 按连接记忆外观
- 快捷键自定义（Keymap）
- 多套配置文件的切换
