# 06 · 查询编辑器

## 1. 界面

```
┌─ 工具栏 ────────────────────────────────────────────────────────────┐
│ [▶ 执行 ⌘↩] [▶▶ 执行全部 ⇧⌘↩] [停止 ⌘.] │ [打开] [另存为]  │
├─────────────────────────────────────────────────────────────────────┤
│  1  SELECT id, name                                                  │
│  2  FROM users                                                       │
│  3  WHERE age > 18;                                                  │
│  4                                                                    │
│  5  SELECT COUNT(*) FROM orders;                                     │
├═ 可拖拽分隔条 ══════════════════════════════════════════════════════┤
│ [结果 1] [结果 2] [错误 ●]                   共 2 条 · 耗时 42 ms    │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│                        结果网格（只读）                              │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
```

- 编辑器与结果区之间的分隔条可以上下拖拽，比例会被记住
- 打开的查询标签标题是 `查询 1`、`查询 2`…，可以右键重命名

## 2. 编辑器

### 基本能力

- 语法高亮：关键字、函数名、类型名、字符串、反引号标识符、数字、注释、变量、操作符
- 左侧行号
- 当前光标所在的语句整段加一层淡背景，方便看出「执行当前语句」会跑哪一段
- 自动缩进：换行时保持上一行的缩进
- `Tab` 插入 4 个空格（可在偏好调整）
- 查找（`⌘F` 打开系统的查找条）
- 撤销 / 重做

### 明确不做

- 自动补全
- SQL 格式化 / 美化
- 多光标
- 分屏

### 必须关闭的自动替换

输入 `'`、`"`、`--` 时**绝不能**被替换成弯引号或长破折号。这是 SQL 编辑器最容易踩的坑，必须确保系统级的智能引号 / 智能破折号 / 拼写纠正全部关闭。

### 脚本自动保存

- 编辑内容每隔一小段时间自动保存为草稿
- 重新打开查询标签时，如果偏好里开启了「恢复上次的脚本内容」，会恢复上一次的编辑内容（连接后还原出来的查询标签同样适用）
- 关闭查询标签不提示保存（除非该标签是从磁盘打开或另存过的文件且又有新改动）

## 3. 执行

### 执行范围

| 快捷键 | 行为 |
| --- | --- |
| `⌘↩` | 有选中内容 → 执行选中部分；没有选中 → 执行光标所在的语句 |
| `⇧⌘↩` | 执行全部语句 |
| 工具栏下拉 | 可以把默认行为改成「执行全部」，设置会被记住 |

- 语句按分号切分，字符串里、反引号里、注释里的分号不算分隔符
- 最后一段即使没有分号也算一条语句
- 空语句和纯注释段会被跳过

### 执行中

- 「执行」按钮变成「停止」（`⌘.`）
- 状态栏显示进度：`正在执行… 已接收 12,480 行（2.1 MB）（3.4 秒）`
- 结果边收边显示，不用等全部返回
- 结果很大（超过 10 万行）时提示 `结果较大，可随时停止`
- 停止后已经收到的部分结果会保留展示

### 出错时

- 默认行为：**遇到第一个错误就停止**，后续语句不再执行
- 可以在偏好里改成「继续执行剩余语句」，这样一次能看到所有错误（适合跑迁移脚本）
- 出错的语句在结果标签上标红

## 4. 结果展示

### 结果标签

执行多条语句时，每条语句的结果是一个标签：

```
[结果 1] [结果 2] [完成] [错误 ●]
```

| 标签文字 | 含义 |
| --- | --- |
| `结果 N` | 一条查询，有返回行 |
| `完成` | 非查询语句，显示影响行数与 `last_insert_id` |
| `错误` | 该语句失败 |

- 标签超过 24 个时折叠，前 23 个直接显示，其余收进一个 `…` 下拉
- 右键标签：`关闭` / `关闭其他` / `复制这条语句` / `复制结果`
- 结果网格是**只读**的（想改数据请用表数据视图）

### 结果网格

- 复用表数据视图的只读网格（没有右侧字段栏，也不可编辑）
- 支持：排序（本地排序，不重新查询）、调整列宽、列显隐、复制、快速查看、导出
- 没有返回行的语句（例如 `UPDATE`）显示一个简单面板：`影响 3 行 · 耗时 12 ms · last_insert_id = 42`

### 无结果

`查询成功，0 行，耗时 3 ms`

## 5. 查询历史

左侧栏底部的 `查询历史` 入口，作为独立标签打开：

```
┌─ 查询历史 ─────────────────────────────────────────────────┐
│ [ 搜索 ]  [全部连接 ▾]  [今天 ▾]              [清空历史]   │
├────────────────────────────────────────────────────────────┤
│ 14:32:07  ✓  42 ms   1,204 行   SELECT id, name FROM …     │
│ 14:31:55  ✗  3 ms               UPDATE users SET …         │
│ 昨天 18:02  ✓  812 ms  3 行      INSERT INTO orders …      │
├────────────────────────────────────────────────────────────┤
│  单击 → 下方预览完整 SQL                                    │
│  双击 → 插入到当前查询标签                                   │
│  右键 → 复制 / 在新标签打开 / 删除该条                       │
└────────────────────────────────────────────────────────────┘
```

- 只记录**从 SQL 编辑器执行**的语句
- 表分页、元数据读取这类客户端自动发出的查询不记录
- 支持按 SQL 内容搜索、按连接过滤、按时间范围过滤
- 默认保留最近 5000 条
- 「清空历史」清空当前连接的记录；按住 `⌥` 点击清空所有连接
- 每条记录包含：时间、成功/失败、耗时、返回行数或影响行数、完整 SQL

## 6. Console Log

左侧栏底部的 `Console Log` 入口，作为独立标签打开：

```
┌─ Console Log ──────────────────────────────────────────────┐
│ [全部 ▾] (全部 / 仅数据语句 / 仅元数据)     [复制] [清空]  │
├────────────────────────────────────────────────────────────┤
│ 14:32:07.123 [data]  app_dev  42 ms   1204 行               │
│   SELECT `id`,`name` FROM `app_dev`.`users` ORDER BY …      │
│                                                             │
│ 14:32:06.998 [meta]  app_dev  3 ms                          │
│   SELECT COLUMN_NAME, … FROM information_schema.COLUMNS …   │
│                                                             │
│ 14:32:06.541 [data]  app_dev  ✗ 1064                        │
│   SELECT * FORM users                                       │
└────────────────────────────────────────────────────────────┘
```

- 记录**所有**发给数据库的语句，包括客户端自动发出的元数据查询、分页查询、事务控制语句、取消查询的操作
- 两类标签：`[data]` 是用户发起的，`[meta]` 是客户端自动发的
- 可以按类别过滤
- 每条展开后可以看到完整 SQL 与执行结果概要
- 只保留最近 5000 条（更早的自动丢弃）
- 默认只存在内存里，关掉 App 就没了；可在偏好里开启「写入日志文件」
- 列表默认跟随滚动到底部；用户手动向上滚动后暂停跟随，并显示「回到底部」按钮

## 7. 脚本文件

| 操作 | 行为 |
| --- | --- |
| `⌘O` | 打开 `.sql` / `.txt` 文件到新的查询标签 |
| `⇧⌘S` | 当前脚本另存为 |
| 关闭标签 | 若关联过文件且有未保存改动 → 提示保存；草稿内容不提示 |

## 8. 只读模式下

连接处于只读模式时：

- 执行前会检查语句类型，写操作（增删改、DDL、授权等）被拒绝
- 混合脚本里只执行安全语句，被拒绝的语句在结果标签中标红并说明原因
- 工具栏提示：`只读模式：写操作已被禁用`（允许的语句类型清单见 [09-readonly-mode.md](09-readonly-mode.md) §4）

详见 [09-readonly-mode.md](09-readonly-mode.md)。

## 9. 取消长查询

- `⌘.` 或点工具栏「停止」
- 停止后会向数据库发送取消请求，服务器端正在跑的语句会被中止
- 如果取消失败（例如权限不足），会提示：`取消失败，查询仍在服务器上运行`

详见 [12-feedback.md](12-feedback.md)。
