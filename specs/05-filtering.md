# 05 · 过滤器

过滤器只影响**看什么**，不改动任何数据。

## 1. 行过滤器

按 `⌘F` 打开（或点网格下方条的 `筛选`），面板出现在数据网格上方的一条横条中。

```
┌─ 过滤器 ────────────────────────────────────────────────────────────┐
│ ☑ [ name        ▾ ] [ 包含      ▾ ] [ 张             ]  [ + ] [ − ] │
│ ☑ [ age         ▾ ] [ 大于等于  ▾ ] [ 18              ]  [ + ] [ − ] │
│                                                                      │
│  组合方式  (•) 全部满足   ( ) 满足任一     [ 高级 / 直接写条件 ]     │
│                                            [ 重置 ]  [ 应用 ]        │
└──────────────────────────────────────────────────────────────────────┘
```

### 条件行

每行三个部分：**列 + 操作符 + 值**。

- 最左侧的勾选框决定这一条是否参与过滤。取消勾选可以临时停用某个条件而不删掉它
- 列下拉：列出当前表的所有列，列很多时带搜索框
- 值输入框在不需要值的操作符下会自动禁用
- `+` 添加一行（`⌘I`）；过滤器面板打开时 `⌘I` 归面板，与数据网格里的「插入新行」不冲突（见 [02-workspace.md](02-workspace.md) §9）。`−` 删除该行不给快捷键，避免与「导入 CSV…」的 `⇧⌘I` 冲突
- 按 `Esc` 关闭面板（条件会保留，只是隐藏）

### 可用操作符

| 操作符 | 含义 | 需要值 |
| --- | --- | --- |
| 等于 | 精确匹配 | 是 |
| 不等于 | 精确排除 | 是 |
| 包含 | 文本包含 | 是 |
| 不包含 | 文本不含 | 是 |
| 开头是 | 前缀匹配 | 是 |
| 结尾是 | 后缀匹配 | 是 |
| 大于 / 大于等于 / 小于 / 小于等于 | 数值或日期比较 | 是 |
| 在区间内 | 两个值之间（含两端） | 是，两个 |
| 在列表中 | 匹配列表中的任一值（逗号分隔） | 是 |
| 为空 | `NULL` | 否 |
| 不为空 | 非 `NULL` | 否 |

### 组合方式

- `全部满足`（AND）或 `满足任一`（OR），二选一，作用于所有勾选的条件
- 不支持嵌套括号分组（已知限制）

### 高级模式

点「高级 / 直接写条件」后，可以自己写过滤条件，例如：

```
id IN (1, 2, 3) AND status <> 'deleted'
```

- 切换时会提示：`高级条件不会被校验，请自行确认语法正确`
- 高级模式与条件行互斥，切换时清空另一侧

### 应用

- 点「应用」后重新加载
- 点「重置」清空所有条件并重新加载
- 应用失败（例如引用了不存在的列）时，在面板顶部显示错误，面板保持打开，方便修正

### 快速过滤

| 操作 | 效果 |
| --- | --- |
| 右键列头 → `按此列筛选` | 新增一条「列 = 该列」的等于条件，值留空并聚焦，等用户填写 |
| 右键单元格 → `按此值筛选` | 新增一条「列 = 该列」且值等于该单元格内容的条件，立即应用 |
| 右键单元格 → `排除此值` | 同上，操作符为「不等于」 |
| 外键单元格点 `↗` | 在新标签打开被引用表，并自动加上「主键 = 该值」的条件 |
| ENUM / SET / 布尔列 | 值输入框变成下拉选项，避免手输错 |

### 记忆

每个表最后一次使用的过滤条件会被记住，下次打开这张表时恢复。可以在偏好里关闭这个行为。

## 2. 列过滤器

按 `⌥⌘F` 打开（或点网格下方条的 `列`），控制显示哪些列。

```
┌─ 显示的列 ────────────────────┐
│ [ 搜索列… ]     [全选] [全不选]│
│ ☑ id              (主键)      │
│ ☑ name                        │
│ ☐ content         (LONGTEXT)  │
│ ☑ created_at                  │
├───────────────────────────────┤
│       [ 取消 ]  [ 应用 ]      │
└───────────────────────────────┘
```

规则：

- 至少保留一列可见，否则「应用」禁用并提示
- 列显隐是纯显示行为，不影响数据加载（隐藏的列仍会被查询）
- 列显隐只影响数据网格；右侧字段栏始终列出全部字段（见 [03-data-browsing.md](03-data-browsing.md) §7）
- 列显隐状态与列宽一起记住

## 3. 与其他操作的相互影响

| 操作 | 行为 |
| --- | --- |
| 应用 / 重置过滤器 | 重新加载 |
| 有未提交改动时改过滤器 | 允许，但先提示「切换过滤条件会重新加载数据，你的修改会保留在暂存区」 |
| 有未提交改动时改排序 | 同上 |
| 过滤器生效时提交 | 提交成功后按当前过滤条件重新加载；被过滤掉的改动行虽然提交成功但不会出现在结果里 |
| 过滤条件引用了不存在的列 | 应用时直接在面板顶部报错并指出是哪一条 |
| 导出一张被过滤的表 | 导出的是**当前过滤条件下**的数据，导出面板里会明确写出这一点 |

## 4. 已知限制

- 不支持嵌套括号分组（例如 `(A AND B) OR C`）
- 所有条件只能是 AND 或 OR 中的一种，不能混用
- 高级模式不做语法校验
