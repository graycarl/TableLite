# 12 · 提示、确认与错误

本文统一规定界面上的反馈方式与文案风格，避免各处不一致。

## 1. 反馈的四种形态

| 形态 | 用在哪 | 是否打断 |
| --- | --- | --- |
| 常驻进度 | 查询执行（编辑器状态栏）、提交（网格遮罩）、导出（导出面板） | 否 |
| 轻提示（Toast） | 瞬时提示、复制成功、提交成功、导出完成 | 否，几秒后自动消失 |
| 确认弹窗 | 破坏性操作前的确认 | 是 |
| 错误面板 | 需要用户看清原因的错误 | 是 |

原则：能用轻提示和常驻进度解决的，不要弹窗。

「结果概要」**不含提交结果**：提交成功走轻提示（见 §3），过程进度留在发起操作的视图里（见 §2）。

## 2. 进行中的进度

窗口底部**没有**常驻状态栏（2026-09-24 去掉，见 [02-workspace.md](02-workspace.md) §7）。长耗时操作都在**发起它的地方**显示进度，不开全局进度条：

| 操作 | 进度显示在 |
| --- | --- |
| 查询执行 | 查询编辑器自己的状态栏与结果区：`正在执行… 已接收 12,480 行（2.1 MB）（3.4 秒）` |
| 提交 | 网格上的遮罩：`正在提交 3/7…` |
| 导出 | 导出面板：`正在导出… 已写入 129,480 行（24.1 MB）` |

- 导出面板在导出期间一直开着，所以不再另做全局进度提示
- 表数据标签的行数与 `筛选` / `列` / `导出` 入口在网格下方条（见 [03-data-browsing.md](03-data-browsing.md) §2）
- 连接信息（服务器版本 / 字符集 / 只读 / SSH 隧道端口）在工具栏连接切换器的悬停详情里，不常驻显示

## 3. 轻提示

出现在窗口顶部中间，2.5 秒后淡出，不遮挡操作。

| 场景 | 文案 |
| --- | --- |
| 进入只读连接 | `该连接处于只读模式，所有写操作已被禁用。` |
| 提交成功 | `已提交 7 处修改 · 128 ms` |
| 复制成功 | `已复制 12,480 行（2.1 MB）` |
| 导出完成 | `导出完成：129,480 行 → articles.csv` + 「在 Finder 中显示」按钮 |
| 导入完成 | `导入完成：成功 12,480 行，失败 0 行` |
| 已断开 | `连接已断开` |
| 重连成功 | `已重新连接` |
| 只读拦截（单条） | `只读模式：已跳过 1 条写操作语句` |

## 4. 确认弹窗

只在**不可撤销**或**可能丢数据**的操作前出现。

| 场景 | 是否有确认 | 确认方式 |
| --- | --- | --- |
| 删除连接 | 是 | 普通确认按钮 |
| 关闭有未提交改动的标签 | 是 | 三选一：提交 / 放弃并关闭 / 取消 |
| 放弃多于 5 条改动，或改动里包含删除 / 新增 | 是 | 普通确认 |
| 截断表 | 是 | **手动输入表名** |
| 删除表 | 是 | **手动输入表名** |
| 覆盖已存在的导出文件 | 是 | 普通确认 |
| 关闭只读模式 | 是 | 普通确认 |
| 清空查询历史 / Console Log | 是 | 普通确认 |

确认弹窗的按钮措辞必须**具体**，不要用「确定 / 取消」：

```
[ 取消 ]   [ 放弃修改 ]   [ 提交并继续 ]
```

而不是

```
[ 取消 ]   [ 确定 ]
```

## 5. 错误面板

### 结构

```
┌─ <标题：一句话说清发生了什么> ────────────────────────┐
│  <必要时：发生在哪一步 / 哪条语句>                     │
│                                                       │
│  <原始错误信息，原样展示，不翻译>                      │
│   错误码 · SQLSTATE · 服务器 message                   │
│                                                       │
│  <必要时：相关的那条 SQL>                              │
│                                                       │
│  <对用户的影响：数据是否已改动、是否需要人工处理>      │
│                                                       │
│  [ 查看详细输出 ]              [ 关闭 ]  [ 重试 ]     │
└───────────────────────────────────────────────────────┘
```

### 必须遵守的规则

1. **服务器返回的错误原文不翻译、不改写、不截断**。翻译过的错误信息会让用户无法搜索。
2. 错误码与 SQLSTATE 必须显示。格式：`[错误 1062] SQLSTATE 23000`
3. 必须说明**数据现在是什么状态**。例如：
   - `事务已回滚，你的修改都还在暂存区里，尚未生效。`
   - `提交超时，事务状态未知，请在数据库中手动核对这几行的数据。`
   - `导出中断，文件不完整。`
4. 如果能给出下一步动作，就提供按钮（`重试`、`重新连接`、`查看详细输出`）。

### 常见错误的附加说明

| 错误 | 附加的一句说明 |
| --- | --- |
| `1045` 认证失败 | `请检查用户名与密码。` |
| `1049` 数据库不存在 | `请检查连接配置里的数据库名，或留空。` |
| `1130` 主机不允许 | `该账号不允许从当前 IP 连接，请检查数据库的访问白名单。` |
| `1062` 唯一键冲突 | `有一行的值与已有数据重复。` |
| `1064` 语法错误 | `请检查这条语句。` |
| `1205` 锁等待超时 | `有其他事务长时间持有锁，稍后重试。` |
| `1213` 死锁 | `事务已被回滚，请重试。` |
| `2006` / `2013` 连接丢失 | `连接已断开，请手动重新连接。` |
| SSH 认证失败 | `请检查 SSH 用户、密钥或密码。` |

## 6. 加载与空状态

| 场景 | 表现 |
| --- | --- |
| 首次读取数据 | 网格区域显示骨架占位（不是转圈图标） |
| 切换显示条数 / 排序 / 过滤 | 保留旧数据并叠加半透明加载遮罩，避免闪烁 |
| 网络慢（超过 1 秒） | 网格下方条的行数后显示耗时 |
| 超过 10 秒 | 网格下方条的行数后附带「取消」按钮 |
| 空结果 | 明确说明是「没有数据」还是「查询成功但没有返回行」 |

## 7. 危险状态的视觉提示

| 状态 | 表现 |
| --- | --- |
| 有未提交改动 | 标签标题的橙点 + 提交按钮上的角标数字 |
| 只读连接 | 锁图标 + 连接颜色带 + 标题栏「（只读）」 |
| 连接异常 | 红点 + 内容区灰色遮罩 + 「重新连接」按钮 |
| 结构视图可能过期 | 顶部黄色提示条 + 「刷新」按钮 |

## 8. 文案规范

- 用**主动语态**、**陈述事实**，不用「您」也不用感叹号
- 术语统一：

| 统一用词 | 不要用 |
| --- | --- |
| 数据库 / 库 | schema（英文混用） |
| 标签 | Tab / 页签 |
| 表数据视图 | 数据浏览器 / Grid |
| 变更暂存 / 未提交的修改 | pending change（英文混用） |
| 提交 | 保存 / Commit |
| 放弃 | 撤销 / Discard |
| 快速查看 | Quick Look |
| 连接 | 数据源 / 会话 |

- 按钮文案 2–4 个字，文件名、路径、SQL 用等宽字体
- 数字与单位之间加空格：`12.3 KB`、`128 ms`、`300 行`
- 时间用 `HH:mm:ss`；跨天显示 `昨天 18:02`
