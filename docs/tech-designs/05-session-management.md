# 05 · 连接会话管理

需求见 [`specs/01-connections.md`](../../specs/01-connections.md)。本文只讲实现决策。

## 1. 模型

- `Connection`：id / 名称 / 颜色 / 只读标记 / MySQL 配置 / SSH 配置 / 时间戳。
- **密码与 passphrase 不在 `Connection` 里**，按需从 Keychain 取（`02-persistence.md` §3）。
- 序列化格式见 `02-persistence.md` §2。

## 2. 会话与全局管理

- `SessionManager` 是**唯一**持有连接的地方；视图不直接持有 `MySQLSession`。
- `ConnectionSession` 聚合：连接配置、状态、MySQL 会话、可选隧道、元数据仓库、标签列表。
- 连接上限由偏好决定（默认 8，见 `specs/11-preferences.md` §2）；超出时拒绝并提示先断开。
- **切换连接不关闭会话**；只有显式断开或空闲回收才关闭。
- 每个 session 一个 `MetaRepository` —— 元数据缓存不能跨连接共享。

## 3. 连接流程

分步推进并把步骤反映到 UI，依次显示三条进度提示：SSH 隧道 → MySQL 连接 → 读取服务器信息（见 `specs/01-connections.md` §5）；库列表在服务器信息之后拉取，不单独作为一条进度提示。

- SSH 隧道失败与 MySQL 失败用不同的错误类型与文案（`ConnectFailure.step` 区分）。
- SSH 失败带上 stderr 的最后 4 KB，这是排查的唯一线索。
- **数据库名不存在不算连接失败**：连接本身是成功的，界面上提示「连接配置里的数据库 xxx 不存在」。

### 3.1 测试连接

走同一条代码路径，但完成后立即关闭、不写入 `SessionManager`、不写查询历史。

## 4. 服务器信息

一次查询取全版本、字符集、排序规则、`sql_mode`，避免多次往返。`SHOW DATABASES` 的结果在客户端过滤系统库（`SHOW` 不支持 `WHERE`），并保留一份未过滤列表备用。

## 5. 空闲回收

- 周期检查：空闲超过 5 分钟**且没有标签**的会话才断开。
- 有标签的会话不回收，避免用户切回来发现被断开。
- 回收只断开，不删除会话对象与标签；界面显示遮罩与「重新连接」。

## 6. 连接失效与重连

- 心跳失败或错误码 `2006` / `2013` → 标记失效并通知 `ConnectionSession`。
- 状态置为失败，**不自动重连**（刻意选择，见 `13-open-questions.md` L7）。
- 用户点「重新连接」：必要时重建隧道、重建 `MySQLSession`、刷新对象树与当前页；**标签里的暂存改动不清空**。

## 7. 退出与清理

`applicationShouldTerminate` 返回 `.terminateLater`：

1. 找出所有有未提交改动的标签，逐个弹确认（提交 / 放弃 / 取消关闭）；
2. 全部处理完后：关闭所有 MySQL 会话、停止所有隧道（同步等待，最多 2s 后 SIGKILL）、flush Console Log。

**硬约束：退出后不得残留 ssh 进程**（冒烟脚本会检查）。

## 8. 标签现场还原（`session.json`）

- **启动不恢复会话**：App 每次启动都进连接列表，不建会话骨架、不自动连接（决策 S36，`specs/01-connections.md` §1）。启动时列表里不会出现待重连的条目。
- `session.json` 只承担「按连接记住标签现场」：按 `connectionID` 保存该连接的库 / 活动标签，以及每个标签的显示条数、排序、过滤、隐藏列等。
- 用户连上某个连接时，才把它的快照应用到一个新建的会话上；没有快照的连接就是空白工作区。已有会话时直接复用，不重放快照。
- 落盘是读-改-写：本次运行中打开过的连接，快照以当前会话为准（即使标签已全部关光也要写空快照，避免下次又还原出旧标签）；没打开过的连接的旧快照原样保留。
- 删除连接时顺带删掉它的快照。
- 写文件用「临时文件 + 原子替换」（`02-persistence.md` §2.1）。
- 同一运行期内断开 / 被空闲回收的会话仍保留标签，并提供逐行「点击重连」与「恢复全部」（§5、§6）。

## 9. 查询标签的草稿存储

- 每个查询标签一个 `draftId`，编辑内容防抖 1s 落盘。
- 标签关闭时删除对应草稿（已另存为磁盘文件的除外）。
- 启动时清理超过 30 天且未被 `session.json` 引用的孤儿草稿。

## 10. 状态栏数据来源

状态栏连接区显示：状态点、名称、当前库、服务器版本（首次连接时取，不重复查询）、字符集、只读标记。
