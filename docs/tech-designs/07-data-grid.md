# 07 · 数据网格

## 1. 为什么用 AppKit

SwiftUI 的 `Table` 不支持十万行级稳定滚动、冻结列、细粒度列宽持久化、按单元格区分的右键菜单，以及精确控制「焦点单元格 / 选区」。因此网格用 `NSTableView`（view-based），经 `NSViewRepresentable` 嵌入 SwiftUI。

**网格是只读的**：单元格不承载编辑器，所有值修改都在右侧字段栏（`14-row-inspector.md`）。数据源用 Diffable，行身份用「主键值字符串」而非行号，刷新后可保持选中状态。

## 2. 列模型

- 列的显示顺序 = 结果集列顺序。
- 列宽首次按内容估算（采样 + 表头，设上限），用户拖拽后按「连接 + 库 + 表 + 列名」持久化。
- 结果集的投影列需记录它对应的真实表列，以及它是否是大字段截断投影、配套的长度别名是什么。

## 3. 表数据视图的 SQL 生成

### 3.1 大字段两阶段加载（关键设计）

整列 `SELECT *` 拉回大字段会让一页数据膨胀到 GB 级，因此对「大字段」做投影 + 按需二次加载：

- **判定**：TEXT / BLOB / JSON / GEOMETRY 系列，且偏好 `grid.lazyLargeColumns` 开启（默认开）。
- **首屏**：用 `LEFT(col, N)` 取前 N 字节（默认 4 KB，偏好可调），并附带一个长度列用于展示「共 1.2 MB」；长度列不显示，由网格消费后并入单元格状态。
- **排序必须用真实列名**，不能按截断前缀排序。
- **二次加载**：选中该行且字段栏可见 / 打开 Quick Look / 开始编辑该字段时，用行定位键取完整值。
  - 行必须能唯一定位（有主键，或有「全部列 NOT NULL 的唯一索引」，判定同 `08-pending-changes.md` §7）；否则保持截断并提示「无法定位行以加载完整内容」。
  - 结果缓存到单元格，直到标签关闭或 `⌘R`；字段栏与 Quick Look 共用这份缓存。
- 表没有大字段时不生成任何截断投影。

**安全保证**：截断值永远不会被写回数据库（见 `08-pending-changes.md` §9）。

### 3.2 列清单的来源

列清单来自 `information_schema.COLUMNS`（`MetaRepository` 缓存），**不用** `SELECT * LIMIT 0`：能拿到完整类型文本（`tinyint(1)`、`enum(...)`）、注释、生成列标记，且顺序稳定。不可见列默认不显示。

### 3.3 ORDER BY 与分页稳定性

- 有主键 → 按主键排序。
- 无主键但有「全部列 NOT NULL 的唯一索引」→ 按该唯一索引排序。
- 两者都没有 → **整表只读**，仍显示数据但省略 `ORDER BY`，状态栏提示「分页顺序不保证，且不可编辑」。
- 用户点列头排序时追加主键作为次级排序键，保证稳定。

### 3.4 行数估算

用 `information_schema.TABLES` 的估算值，显示为「约 N 行」；估算不可靠时明确标注。**绝不在打开表时自动跑 `COUNT(*)`**，只在用户点「精确统计」时执行。

## 4. 单元格渲染

单元格只读展示，关键视觉状态：

- `NULL` 灰斜体；已修改橙色底 + 角标；新增行整行绿色底、行号列显示 `+`；删除行删除线 + 红底。
- 截断值末尾加 `…`，tooltip 说明「原始长度 x，按需加载」。
- 二进制显示为 `«BLOB 12.3 KB»` 或 hex。
- 外键列追加 `↗`，点击在新标签打开被引用表并定位到该行。
- 主键列表头加粗 + 钥匙图标；Commit 失败行红底 + 感叹号。

行号列固定最左；已修改 / 已删除的行在行号上加标记，新增行的行号列显示 `+`。

## 5. 选择、焦点与字段栏

- 单击更新焦点单元格；拖动 / `⇧` 点击更新选区；点行号更新选中行；方向键移动焦点。
- 双击可编辑表 → 展开字段栏并聚焦对应编辑器；双击不可编辑表 → 打开快速查看。
- 选区变化后**立即**把焦点回写 ViewModel，不要等到下一轮 runloop，否则字段栏会晚一帧。
- 字段栏的编辑结果只影响「已修改」标记，不回写选区。

## 6. 排序

- 点击列头循环：无 → 升序 → 降序 → 无；`⇧` 点击追加多列排序。
- 排序变化 → 重置到第 1 页并重新查询。
- 「无排序」等价于按主键（或唯一键）排序（§3.3）。

## 7. 分页

- 每页默认 300，可选若干档与自定义。
- 查询 `pageSize + 1` 行来判断「是否有下一页」，多出的一行不显示。
- 翻到很深的页（偏移超过 10 万行）时状态栏提示「偏移量很大，翻页会越来越慢；建议用过滤器缩小范围后再翻页」（L11）。

## 8. 复制

支持：单元格值、行、选中行、整列、JSON、Markdown、CSV（含 / 不含表头）、SQL INSERT、列名、DDL。

- SQL INSERT 复用 `SQLValueLiteral`，与 Commit 的语句一致。
- 大结果复制后给出轻提示（已复制行数 / 体积）。

## 9. 快速查看

- 触发：中键 / 选中后 `Space` / 右键。
- 面板独立浮动、可调整、`Esc` 关闭。
- 按内容类型展示：JSON 格式化折叠、长文本、二进制 hex dump + 导出文件、图片直接显示、日期附本地解析。
- 若目标是大字段且未加载，先触发二次加载并显示 loading。

## 10. 性能预算

| 指标 | 目标 |
| --- | --- |
| 打开百万行表（300 行/页） | < 500 ms |
| 300 行滚动 | 稳定 60 fps |
| 字段栏编辑到界面更新 | < 16 ms |
| 1000 行/页内存 | < 20 MB（不含大字段） |
