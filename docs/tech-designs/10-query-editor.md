# 10 · SQL 编辑器

## 1. 组成

工具栏（执行 / 执行全部 / 停止 / 打开 / 另存为）+ 编辑器 + 可拖拽分隔条 + 结果区（只读网格 + 结果标签）。

## 2. 文本视图

`SQLEditorTextView` 封装 `NSScrollView` + `NSTextView`。

**硬约束：必须关闭全部智能替换** —— 智能引号、智能破折号、文本替换、拼写纠正、数据检测。不关的话 SQL 里的 `'` 会变成弯引号、字符串里的 `--` 会变成长破折号。这是本项目最常见的坑。

其他：行号用自绘 `NSRulerView`（并标出当前语句起始行）；Tab 插入固定个数空格；简单自动缩进（继承上一行前导空白），不做完整格式化。

## 3. 语法高亮

- 手写单向扫描器，输出 `(range, token)`；token 分类包括关键字、函数、类型、字符串、反引号、数字、注释、变量、参数、运算符、标点、标识符。
- **必须正确处理**：字符串内的 `--` 与 `;`、`''` / `\'` / `""` / `\"` 转义（兼容 `NO_BACKSLASH_ESCAPES`）、反引号内任意内容、`/*! … */` 版本注释、`#` 注释。
- **增量着色**：只对受影响的段落范围重新着色，避免全文重扫。
- 颜色主题跟随系统深浅，不做自定义（见 [`specs/00-scope.md`](../../specs/00-scope.md) §2.2）；光标所在语句的所有行加一层极淡背景。

## 4. 语句拆分

- 分号分隔，但**忽略**字符串 / 反引号 / 注释内的分号。
- 结尾没有分号的最后一段（非空）也算一条；空语句 / 纯注释段跳过。
- 保留原始内容（含结尾分号），下发时不再补分号。
- 每条语句带类型（查询 / DML / DDL / 其它），用于只读拦截与历史分类；类型判定见 §10。

## 5. 执行

### 5.1 执行哪段

- `⌘↩`：有选区执行选区，无选区执行光标所在语句。
- `⇧⌘↩`：执行全部。

### 5.2 下发方式

**逐条下发**：按拆分结果一条条发给服务器，每条语句单独走一次查询。

理由：要支持 `editor.stopOnError` 的两种取值（§5.4），并让只读拦截能在下发前逐条过滤（§10）。同一连接上顺序执行，会话变量、临时表等会话状态照常延续；代价是比整包脚本多几次往返，在编辑器场景可以接受。

### 5.3 执行中的 UI

工具栏「执行」变「停止」（`⌘.`）；编辑器自己的状态栏显示已接收行数与体积；结果流式追加到结果网格；超大结果提示可随时停止。

### 5.4 单条语句出错

服务器报错 → 该语句标红。**后续是否继续由偏好决定**：`editor.stopOnError` 默认 **true**（遇错即停，不再下发后面的语句），可关闭以继续跑完（类似 `mysql --force`）——因为语句是逐条下发的，上层不发下一条即可，两种取值都能精确实现。

### 5.5 默认数据库与 `USE`

- 执行的语句默认落在 `ConnectionSession.selectedDatabase` 上：切库时就向服务器发过一次 `USE`（`05-session-management.md` §11），编辑器不再逐条带库名。
- 脚本里的 `USE` 用 `SQLStatementClassifier.isUseStatement` 识别，在只读检查**之前**拦截：不下发，生成 `.blocked` 结果标签（标题 `已拦截`，原因 `请通过侧栏切换数据库`），并给一条轻提示。只读模式与普通模式一致。
- 结果标签文字：只读拦截用 `只读拦截`，`USE` 拦截用 `已拦截`（`QueryResultTab.blockedLabel`）。

## 6. 结果标签

- 每个结果一个标签：查询结果（只读网格）/ 影响行数 / 失败。
- 结果网格只读，但支持本地排序（对内存数据排序，不重新查询）、复制、导出、快速查看、列宽调整、列过滤。
- 标签过多时折叠成「前若干 + …」下拉；右键可关闭 / 关闭其他 / 复制语句 / 复制结果。

## 7. 查询历史

- 入口在侧栏，数据来自 `history.sqlite3`（`02-persistence.md` §4）。
- 只记录 SQL 编辑器的语句；网格数据与元数据查询不记录。
- 搜索为 SQL 子串匹配，结果限量；双击插入到当前查询标签；可复制 / 在新标签打开 / 删除单条；清空按连接（按住修饰键清空全部）。

## 8. Console Log

- 独立标签，记录**所有**下发语句（含事务控制与 `KILL QUERY`），带 `[data]` / `[meta]` 标签。
- 内存环形缓冲，默认不落盘（`02-persistence.md` §5）；支持过滤、复制、清空。
- 打开时自动跟随底部；用户向上滚动后暂停跟随，并提供「回到底部」。

## 9. 脚本文件

- `⌘O` 打开脚本到新标签，`⇧⌘S` 另存为。
- 每个查询标签自动草稿（防抖 1s），标签随连接还原时恢复（`05-session-management.md` §8）。
- 关闭未保存标签：从未另存过的草稿不提示；曾关联文件且有改动 → 提示保存。

## 10. 只读模式拦截

- **白名单拦截**：发送前只放行 `SELECT` / `SHOW` / `EXPLAIN` / `DESCRIBE` / `DESC`，以及最终为查询的 `WITH …`；其余一律拒绝（`INSERT` / `UPDATE` / `DELETE` / `REPLACE`、`CREATE` / `ALTER` / `DROP` / `TRUNCATE` / `RENAME`、`GRANT` / `REVOKE`、`LOAD DATA`、`CALL`、`SET`、`LOCK` / `UNLOCK` 等）。
- 混合脚本只执行安全语句，被拒绝的语句在结果标签标红说明，且**不中断**后续安全语句。
- UI 提示「只读模式：写操作已被禁用」（提示条不枚举白名单，清单以上面这一行为唯一真源）。
- **注意以 CTE 开头的 INSERT**（`WITH … INSERT`）也必须拦得住 —— 类型判定要看首个真正的写关键字，不能只看第一个 token。
