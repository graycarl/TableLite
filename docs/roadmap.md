## 建议顺序

**P0 → P1 → P2 → P3 → P4 → P5** 是主线，做完 P5 就已经是一个可用的工具了（连上库 → 看数据 → 改数据 → 提交）。

之后按依赖关系补：

```
P6 过滤器  ──┐
P7 SQL 编辑器 ─┤
P8 导入导出  ─┼──► P11 收尾
P9 表结构    ─┤
P10 SSH 隧道 ─┘
```

- **P10（SSH）** 依赖 P1 的连接层，但连接层设计时已按「先建隧道再叠加本地转发」预留，所以可以延后做，不影响主线。
- **P11（收尾）** 里的「只读模式全链路」需要 P5、P7、P8 都完成，因为拦截点分散在多处。

## 每阶段的验收标准

### P0 · 脚手架与依赖

- [ ] `make deps` 能检查并提示缺失的 Homebrew 包
- [ ] `make gen` 能从 `project.yml` 生成 Xcode 工程
- [ ] `make build` 能构建出 `.app`
- [ ] `make run` 能启动一个空窗口
- [ ] 冒烟脚本通过全部 7 项验证（见 `tech-designs/03-mysql-layer.md` §8）

### P1 · 数据访问层

- [ ] 能连接、断开、重连
- [ ] 能执行多条语句并正确区分每个结果集
- [ ] 能流式读取大结果集，内存不随行数线性增长
- [ ] 能取消一个长时间运行的查询
- [ ] 特殊字符（单引号、反斜杠、换行、emoji、`\0`、二进制）往返一致
- [ ] 错误码正确映射到错误类型
- [ ] 保活心跳工作正常

### P2 · 连接管理

- [ ] 能新建 / 编辑 / 复制 / 删除连接
- [ ] 密码写入钥匙串并能回填
- [ ] 删除连接会清理钥匙串
- [ ] 「测试连接」能分步报告结果
- [ ] 多个连接可以同时保持

### P3 · 主界面骨架

- [ ] 连接切换器、库切换器、对象树、标签、状态栏都能工作
- [ ] 对象树能搜索、能折叠、能按需加载
- [ ] 菜单与快捷键按 `specs/02-workspace.md` §9 实现

### P4 · 数据网格

- [ ] 打开 100 万行的表，500 ms 内出首屏
- [ ] 分页、排序、列宽、列显隐都正确且被记住
- [ ] 各类值的显示符合 `specs/03-data-browsing.md` §4
- [ ] 选中行后右侧字段栏显示全部字段（只读阶段）
- [ ] 超长内容延迟加载与快速查看工作正常
- [ ] 各种复制格式正确

### P5 · 编辑与提交（关键）

- [ ] 无主键的表被置为只读并说明原因
- [ ] 网格里无法直接改单元格，编辑统一在右侧字段栏
- [ ] 编辑、插入、复制、删除行的行为符合 `specs/04-data-editing.md`
- [ ] 字段栏里失焦 / `↩` 即进暂存，`Esc` 不写入；校验失败不入暂存
- [ ] 预览的 SQL 与实际提交的完全一致
- [ ] 提交包在一个事务里；任一条失败时全部回滚且暂存区保留
- [ ] 未提交时关标签 / 切连接 / 退出都有确认

### P6 · 过滤器

- [ ] 全部操作符可用
- [ ] 快速过滤可用
- [ ] 转义正确（`%`、`_`、`\`、引号）
- [ ] 高级模式可用

### P7 · SQL 编辑器

- [ ] 语法高亮在各种边界（字符串内注释符、反引号内分号等）都正确
- [ ] `⌘↩` / `⇧⌘↩` 行为正确
- [ ] 多语句结果按语句分标签
- [ ] 能停止执行
- [ ] 查询历史可搜索、可清空
- [ ] Console Log 记录所有语句
- [ ] **智能引号/破折号替换已确认关闭**

### P8 · 导入导出

- [ ] CSV 导出正确（含特殊字符、NULL、二进制）
- [ ] 大表导出内存平稳、可取消
- [ ] CSV 导入向导三步流程完整
- [ ] 能从 CSV 新建表

### P9 · 表结构视图

- [ ] 五个子页签都正确
- [ ] 执行 DDL 后能标记为可能过期

### P10 · SSH 隧道

- [ ] 三种认证方式都能用
- [ ] `~/.ssh/config` 的别名、私钥、跳板机都能生效
- [ ] 主机指纹变化时会明确失败而不是静默接受
- [ ] 隧道断开时状态正确、不自动重连
- [ ] 退出 App 不残留 ssh 进程

### P11 · 收尾

- [ ] `specs/11-preferences.md` 里的选项全部可用且持久化
- [ ] 只读模式在网格、SQL 编辑器、对象树、导入导出四处都生效
- [ ] 空状态、错误文案符合 `specs/12-feedback.md`
- [ ] App 图标
